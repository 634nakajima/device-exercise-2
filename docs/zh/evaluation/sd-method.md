# SD法（Semantic Differential 法）

## SD 法是什么？

**SD 法** 是把人对某事物所感受到的「印象」数值化的方法。它由奥斯古德（Osgood）于 1957 年提出。

例如，听某段音乐时，你也许会获得「明亮的感觉」「舒缓的感觉」「自然的感觉」这样的印象。SD 法就是 **把这类难以言表的感觉转换为数值，使其可以被客观分析** 的工具。

## 用身边的例子来理解

向朋友介绍你喜欢的咖啡馆时，你是不是会这样说明呢？

> 「那家咖啡馆气氛特别沉静，时尚但又很休闲，既不太亮也不太暗……」

SD 法把这件事系统化地进行。准备好「沉静↔喧闹」「时尚↔土气」「明亮↔昏暗」这样的 **形容词配对**，请对方分别用若干个等级作答。

## 原理

### 形容词对

在 SD 法中，把意义相反的形容词成对使用。这被称为「形容词对」。

```
明亮 ──────────── 昏暗
华丽 ──────────── 朴素
舒适 ──────────── 不安
```

### 等级评价

对每个形容词对，用 7 个等级（或 5 个等级）作答。

```
明亮  ◯───◯───◯───◯───◯───◯───◯  昏暗
       3   2   1   0  -1  -2  -3

（「都不是」是正中间的 0）
```

- 觉得接近左侧的形容词，就答在偏左的位置
- 觉得接近右侧的形容词，就答在偏右的位置
- 都不是的话就选正中间

## 用 Google 表单制作问卷的步骤

### Step 1: 表单的制作

1. 打开 [Google Forms](https://forms.google.com)
2. 选择「空白表单」
3. 输入表单的标题（例：「〇〇（作品名）的印象评价问卷」）
4. 追加说明文：

```
关于体验本作品的印象，请回答以下各个项目。
对于每一组形容词对，请选择最接近你印象的位置。
```

### Step 2: 问题项目的制作

对每个形容词对：

1. 点击「添加问题」（＋按钮）
2. 把问题形式改为「**均等刻度**」
3. 设定 1〜7 的刻度
4. 设定标签：
   - 1 的标签: 左侧的形容词（例：「明亮」）
   - 7 的标签: 右侧的形容词（例：「昏暗」）
5. 打开「必填」

::: warning 注意
形容词的左右配置（积极的在左/右）最好随机打乱。如果全部朝同一个方向对齐，可能会产生回答者不加思考就作答的「反应偏差」。
:::

### Step 3: 回答的收集

1. 点击表单右上角的「发送」按钮
2. 用链接图标获取 URL
3. 把 URL 分享给体验者，请他们在体验作品后作答

## 数据的分析步骤

### Step 1: 数据的下载

1. 打开 Google 表单的「回复」标签页
2. 点击表格的图标（绿色）
3. 新的电子表格会打开
4. 「文件」→「下载」→「Microsoft Excel (.xlsx)」

### Step 2: 平均值的计算

在 Excel 中计算各形容词对的平均值。

1. 在回答数据下方的行中输入「平均」
2. 对每一列（形容词对）输入 `=AVERAGE(B2:B11)` 这样的公式
   - B2〜B11 是回答数据的范围（根据回答者人数调整）

### Step 3: 折线图的制作

1. 选择形容词对的名称与平均值
2. 「插入」→「图表」→「折线图」
3. 制作如下的图表：
   - 横轴: 形容词对（显示左侧的形容词）
   - 纵轴: 平均值（1〜7）
   - 加上中线（4.0）会更易读

::: details 图表的样子
```
     1    2    3    4    5    6    7
明亮 ─────────●─────────────────── 昏暗
协调 ────────────●──────────────── 杂乱
舒展 ──────●───────────────────── 局促
独特 ────●─────────────────────── 常见
     ...
```
用点标出各项目的平均值，再用线把它们连起来，就是 SD 法的剖面图。
:::

### Step 4: 考察

一边看图表，一边考察以下几点：

- **是否传达了预期的印象？**
  - 追求「梦幻的氛围」→ 确认「梦幻↔写实」的分数
- **特别强/弱的印象是什么？**
  - 关注平均值极高/极低的项目
- **有没有出乎意料的结果？**
  - 如果并非本意的印象很突出，就思考其原因

::: tip 按体验的各个时点分别评价的情况
如果预计在作品体验过程中印象会有较大变化，就请对方在体验的各个时点（「最初看到作品时」「触摸装置时」「体验结束时」等）分别作答，这样就能分析体验的变化。可以在同一个表单内分成不同的分区来制作。
:::

## 整理成幻灯片

把分析结果整理成 1〜2 张幻灯片：

**幻灯片1: 图表与概要**
- SD 法的剖面图
- 回答者人数、作品名

**幻灯片2: 考察**
- 有特征的印象（高/低的分数）
- 与意图的一致/不一致
- 改进方案
