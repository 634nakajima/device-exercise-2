# UEQ-S（User Experience Questionnaire - Short version）

## UEQ-S 是什么？

**UEQ-S** 是能够简便地测量产品或服务的 **用户体验（UX）品质** 的问卷方法。仅用 **8 个问题**，就能把体验的好坏客观地数值化。

::: tip 与 SD 法的区别
- **SD 法** → 测量作品的「印象」（明亮、华丽、自然等）
- **UEQ-S** → 测量作品的「体验的品质」（好用、有趣、新颖等）

SD 法问的是「感觉如何？」，而 UEQ-S 问的是「用起来怎么样？」。
:::

## 什么是 UX（用户体验）

UX 是用户使用产品或服务的整个体验的品质。以手机应用为例来思考一下：

**易用性（实用性品质）**
- 菜单容易理解
- 操作不会迷茫
- 想做的事马上就能做到

**乐趣・魅力（感性品质）**
- 设计时尚
- 用起来很开心
- 能获得别处没有的体验

好的 UX，就是这两者取得平衡的状态。

## 8 个问题项目

在 UEQ-S 中，对以下 8 组形容词对用 7 个等级作答。

### 测量实用性品质（Pragmatic Quality）的 4 个项目

| # | 左 | 右 | 测量的是什么 |
|---|------|------|------|
| 1 | 有妨碍 (obstructive) | 有帮助 (supportive) | 作品是否帮助了体验者的行动 |
| 2 | 复杂 (complicated) | 简单 (easy) | 操作与理解的难度 |
| 3 | 效率低 (inefficient) | 效率高 (efficient) | 达成目的所需的功夫 |
| 4 | 杂乱 (confusing) | 清晰 (clear) | 操作方法与反应的易懂程度 |

### 测量感性品质（Hedonic Quality）的 4 个项目

| # | 左 | 右 | 测量的是什么 |
|---|------|------|------|
| 5 | 无聊 (boring) | 令人兴奋 (exciting) | 体验的趣味性・兴奋感 |
| 6 | 不吸引人 (not interesting) | 吸引人 (interesting) | 是否刺激好奇心 |
| 7 | 一如既往 (conventional) | 独具匠心 (inventive) | 新颖性・独创性 |
| 8 | 普通 (usual) | 前卫 (leading edge) | 先进・革新的印象 |

::: details 回答的样子
```
有妨碍  ◯───◯───◯───◯───◯───◯───◯  有帮助
         1   2   3   4   5   6   7
```
对每个项目，越接近左侧的形容词就选 1，越接近右侧就选 7。
:::

## 用 Google 表单制作问卷的步骤

### Step 1: 表单的制作

1. 打开 [Google Forms](https://forms.google.com)
2. 选择「空白表单」
3. 标题：「〇〇（作品名）的 UX 评价问卷」
4. 追加说明文：

```
关于体验本作品的感想，请回答以下各个项目。
对于每一组形容词对，请选择最接近你体验的位置。
请凭直觉作答（不要想得太深）。
```

### Step 2: 问题的制作

对 8 组形容词对分别：

1. 点击「添加问题」（＋按钮）
2. 把问题形式改为「**均等刻度**」
3. 设定 1〜7 的刻度
4. 设定标签：
   - 1 的标签: 左侧的形容词
   - 7 的标签: 右侧的形容词
5. 打开「必填」

::: warning 注意顺序
UEQ-S 的问题请按上述顺序排列。因为这是经研究验证过的格式，改变顺序可能会影响结果的有效性。
:::

## 数据的分析步骤

### Step 1: 数据的下载

1. 打开 Google 表单的「回复」标签页
2. 点击表格的图标
3. 「文件」→「下载」→「Microsoft Excel (.xlsx)」

### Step 2: 分数的转换

把回答数据（1〜7）转换为 UEQ-S 的分析用分数（-3〜+3）。

**转换方法：** 回答值 - 4 = 分数

| 回答值 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|--------|---|---|---|---|---|---|---|
| 分数 | -3 | -2 | -1 | 0 | +1 | +2 | +3 |

::: warning 注意消极形容词在左的项目
项目 1〜4（实用性品质）左侧是消极的形容词，所以把回答值原样转换即可。项目 5〜8（感性品质）也是同样。

不过，使用 UEQ-S 的 **官方分析表** 时会自动转换，因此不需要这个步骤。
:::

### Step 3: 分析表的使用（推荐）

UEQ-S 备有官方的分析用 Excel 表。

1. 打开分析表（课上分发，或从 [UEQ 官方网站](https://www.ueq-online.org/) 下载）
2. 先 **复制** 一份表格再使用
3. 把回答数据（1〜7 的值）复制粘贴到「Data」工作表
4. 「Results」工作表中会自动生成图表

### Step 4: 结果的解读

分析表生成的图表主要包含以下内容：

#### 平均值的图表

```
              -3   -2   -1    0   +1   +2   +3
              |    |    |    |    |    |    |
实用性品质 PQ  ─────────────────────■■■■■─────
感性品质  HQ  ──────────────────────────■■■■■
总体   Overall ───────────────────────■■■■──
```

- **+1.0 以上**: 积极的评价
- **-1.0〜+1.0**: 中立（说不上好坏）
- **-1.0 以下**: 消极的评价

#### 基准比较

分析表中包含其他产品的 UEQ-S 结果的基准数据。可以把自己作品的结果与其他产品作比较。

| 基准类别 | 含义 |
|------|------|
| Excellent（最好） | 进入前 10% |
| Good（好） | 进入前 25% |
| Above Average（高于平均） | 进入前 50% |
| Below Average（低于平均） | 后 50% |
| Bad（差） | 后 25% |

## 结果的考察要点

### 实用性品质（PQ）高的情况
→ 操作方法易懂，能凭直觉使用

### 实用性品质（PQ）低的情况
→ 操作方法不易懂，反应与预期不符
→ **改进方案**: 在标签上用图示说明操作方法、调整传感器的反应

### 感性品质（HQ）高的情况
→ 获得了新颖有趣的体验，感到兴奋

### 感性品质（HQ）低的情况
→ 觉得平淡无奇，没有留下特别的印象
→ **改进方案**: 给交互加入意外性、在声音表现上下功夫

### PQ 与 HQ 的平衡

| 模式 | 解读 | 改进方向 |
|------|------|------|
| PQ高・HQ高 | 理想的体验 | 保持・进一步打磨 |
| PQ高・HQ低 | 好用但无聊 | 追加演出或意外性 |
| PQ低・HQ高 | 有趣但不好用 | 改善操作性、追加引导 |
| PQ低・HQ低 | 整体都需要改进 | 重新审视概念 |

## 整理成幻灯片

把分析结果整理成 1〜2 张幻灯片：

**幻灯片1: UEQ-S 的结果图表**
- 实用性品质・感性品质的分数图表
- 基准比较（如果可能）
- 回答者人数

**幻灯片2: 考察**
- 关于 PQ/HQ 的平衡
- 特别高/低的项目
- 改进方案
