# 评价方法概要

制作完作品之后，客观地评价它「传达得如何」「被如何体验」是很重要的。本节介绍课程中使用的两种主要评价方法。

## 为什么要评价？

对自己的作品抱有「做得挺不错」「我觉得挺有趣」这样的主观感受固然重要，但仅凭这些是不够的。进行评价可以：

- **确认意图是否传达到** — 明明追求「恐怖的氛围」却被感受为「快乐」的话，就成了改进的线索
- **发现改进点** — 用数值和图表把弱点可视化
- **可以与他人共享** — 不是「总觉得不错」，而是能用数据说明

## 要测量的东西

在本课程中，主要测量以下两项。

### 印象

使用多个形容词评价从作品中获得的印象。使用「明亮↔昏暗」「华丽↔朴素」这样意义相对的词语配对。

→ 用 **[SD法（Semantic Differential 法）](./sd-method)** 测量

### UX（用户体验的品质）

评价使用作品的体验的品质。UX 大致有两个方面：

| 品质 | 含义 | 例 |
|------|------|------|
| **实用性品质**（Pragmatic Quality） | 易用性・易懂性 | 「操作很直观」「马上就明白怎么用」 |
| **感性品质**（Hedonic Quality） | 乐趣・魅力・新颖 | 「让人兴奋」「前所未有的体验」 |

→ 用 **[UEQ-S（User Experience Questionnaire - Short version）](./ueq-s)** 测量

## 其他评价方法（参考）

本课程主要使用 SD 法与 UEQ-S，不过在研究中也常用以下方法：

| 方法 | 测量对象 | 特征 |
|------|----------|------|
| SAM | 情绪（愉悦度・唤醒度） | 用插图即可凭直觉作答 |
| AttrakDiff | UX（实用性品质・感性品质） | UEQ-S 的原型方法 |
| POMS2 | 心境（消极的方面） | 常用于医疗・心理学 |
| 半结构化访谈 | 体验的细节 | 事先准备问题，根据回答深入追问 |
| 文本挖掘 | 自由填写的倾向 | 分析词句的频率与共现性 |

## 比较・深挖

让评价更深入的方法：

- **改变要素进行比较** — 准备改变了作品内声音或演出的版本进行比较
- **改变媒介进行比较** — 耳机 vs 扬声器、显示器 vs 投影仪
- **与既有作品比较** — 与概念相似的作品或应用进行比较
- **因子分析** — 从 SD 法的结果中统计性地提取印象的类别
