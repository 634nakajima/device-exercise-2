# 第13讲 作品体验会与问卷调查

大家相互体验所有人的作品，并通过问卷收集数据。

## 本讲目标

- 让其他学员体验自己的作品，收集问卷数据
- 获得来自 SD 法・UEQ-S・自由填写的反馈
- 体验所有人的作品，接触多样的表现

## 需要准备的物品

| 物品 | 说明 |
|---------|------|
| 完成的作品 | micro:bit + Pd 补丁 |
| 标签 | 上一讲制作的 A4 面板 |
| 问卷 URL / 二维码 | 通往 Google 表单的链接 |
| 智能手机 | 用于回答问卷 |
| 扬声器 | 用于输出声音 |

---

## 体验会的流程

### 整体的时间安排

| 时间 | 内容 |
|------|------|
| 0:00〜0:15 | 布置 |
| 0:15〜0:20 | 体验会的说明 |
| 0:20〜1:10 | 作品体验 + 回答问卷 |
| 1:10〜1:20 | 收拾・回顾 |

### 1. 作品的布置（15分钟）

按以下步骤进行布置。

1. **器材的连接**
   - 用 USB 线把 micro:bit 连接到电脑
   - 启动 SerialOSCConverter，确认连接
   - 打开 Pd 补丁，把 DSP 设为 ON
   - 连接扬声器，确认能发出声音

2. **标签的设置**
   - 把标签放在作品旁边
   - 调整到体验者容易阅读的位置・角度

3. **问卷的准备**
   - 打印二维码，贴在标签旁边
   - 或者，把问卷 URL 写在纸上放置好

::: warning 布置时的确认事项
- [ ] 声音是否正常输出
- [ ] 传感器是否正确反应
- [ ] 问卷的二维码是否能被扫描
- [ ] 线缆是否安全布线
:::

### 2. 标签的设置

标签要摆放得让以下信息一目了然。

- **作品名** --- 要大而醒目
- **操作方法** --- 包含图示，通俗易懂
- **问卷二维码** --- 放在体验后能立刻作答的位置

### 3. 作品的体验（50分钟）

所有人依次体验各件作品。

**体验的流程（每件作品）:**

1. 阅读标签（1分钟）
2. 自由体验作品（3〜5分钟）
3. 回答问卷（2〜3分钟）
4. 移动到下一件作品

::: tip 体验的诀窍
- 先确认标签上的操作方法再体验
- 尝试各种各样的操作
- 记住体验中的感受，体验后立刻回答问卷
- 如果别人正在体验，就等候顺序或先去别的作品
:::

### 4. 问卷的回答

体验完每件作品后，用智能手机回答问卷。

**回答的步骤:**

1. 用智能手机扫描二维码
2. 回答 SD 法的项目（凭直觉作答）
3. 回答 UEQ-S 的项目（凭直觉作答）
4. 在自由填写栏写下评论
5. 提交

---

## 基于 SD 法的印象评价

在 SD 法（Semantic Differential method）中，使用形容词对以 7 个等级评价作品的印象。

**回答的要点:**

- **不要想得太深** --- 用直觉性的第一印象作答
- **不要总是选中间** --- 尽量选择更接近印象的一侧
- **回答所有项目** --- 不要留空白

::: tip SD 法的详情
关于形容词对的含义与分析方法，请参照 [SD法（印象评价）](/zh/evaluation/sd-method)。
:::

---

## 基于 UEQ-S 的评价

UEQ-S（User Experience Questionnaire - Short version）从 **实用性品质（Pragmatic Quality）** 与 **感性品质（Hedonic Quality）** 两个视角评价用户体验。

**回答的要点:**

- 与 SD 法一样 **凭直觉** 作答
- 回答全部 8 个项目
- 用 7 个等级选择更接近左右哪一侧的形容词

::: tip UEQ-S 的详情
关于各项目的含义与分数的解读，请参照 [UEQ-S（UX评价）](/zh/evaluation/ueq-s)。
:::

---

## 自由填写问卷

在自由填写中，记录用数值无法表达的具体反馈。

**值得写的内容:**

- 特别有趣的部分或操作
- 觉得改进后会更好的地方
- 关于声音或操作的感受
- 对概念的感想

::: tip 建设性的反馈
不要只写「好」「不好」，而是像「因为○○的部分是△△，所以如果□□的话会更好」这样 **具体地** 写，对制作者来说才有参考价值。
:::

---

## 数据收集的注意点

### 作为制作者

- 待在自己作品的旁边，以便 **应对器材故障**
- 但是，不要 **过度向体验者说明操作方法**（这是确认标签能否传达清楚的好机会）
- 如果有人还没回答问卷，就不着痕迹地招呼一声

### 作为评价者

- 体验 **所有的作品** 并回答问卷
- 回答是 **匿名** 的，所以要写下坦率的感想
- 在体验的 **紧接着之后** 回答问卷（时间一久印象就淡了）

### 为了保证数据的质量

- 注意时间分配，让所有人都能体验到全部作品
- 不要在一件作品上停留太久
- 问卷的回答要在 **体验后立刻** 进行

::: warning 重要
问卷数据将在第 14 讲的分析中使用。回答太少会降低分析的精度，因此请注意 **对所有作品都作答**。
:::
