## 声音的收尾

### 噪声对策

确认一下是否产生了不必要的噪声。

| 噪声的种类 | 原因 | 对策 |
|------------|------|------|
| 「啪」的声音 | 数值的急剧变化 | 用 `[line~]` 让数值平滑地变化 |
| 「嗡」的低音 | USB 或电源的噪声 | 缩短线缆、避免形成回路 |
| 「沙沙」的声音 | 噪声成分过大 | 用 `[lop~]` 进行滤波 |
| 声音断断续续 | CPU 负荷过高 | 加大块大小（媒体→音频设置） |

### 传感器的灵敏度调整

为了让体验者容易操作，要调整传感器的反应。

**要点:**

1. **死区的设定** --- 决定传感器的有效范围，排除不需要的数值

把传感器的原始数据用 `clip` 限制在有效范围内，再用 `cyclone/scale` 映射，就可以简洁地设定上限・下限两侧的死区。

```
[传感器数值]
      |
[clip 30 220]           ← 舍弃小于 30・大于 220 的部分
      |
[cyclone/scale 30 220 0 1000]  ← 把有效范围映射到输出范围
      |
[输出]
```

> 详情请参照 [第4讲 裁剪](/zh/lessons/lesson04#裁剪-数值的限制)。

2. **平滑处理（Smoothing）** --- 让数值的变化变得顺滑

使用课程中介绍过的平滑对象吧。

- **`lop~`**: 针对信号的低通滤波器。截止频率越低越平滑
- **`else/smooth~`**: 专门用于平滑的对象。参数越大越平滑
- **`else/s2f~`**: 把平滑后的信号变回数值（`snapshot~` 的替代）

> 详情请参照 [第4讲 平滑处理（Smoothing）](/zh/lessons/lesson04#平滑处理-smoothing)。

## 标签的制作

### 什么是标签

**标签（caption）** 是在展示会场设置在作品旁边的解说面板。它是让体验者理解作品、能够正确操作的重要元素。

### 标签中要包含的内容

| 项目 | 内容 | 例 |
|------|-----|-----|
| **作品名** | 作品的标题 | 海中漫步 |
| **作者名** | 自己的姓名 | 山田太郎 |
| **概念说明** | 说明作品的意图 | 用声音表现深海的世界。micro:bit 的倾斜会改变水深，昏暗时会出现气泡。 |
| **操作方法** | 配图示说明操作方法 | 附插图 |

### 排版的要点

::: tip 推荐用 A4 尺寸制作
- **字号**: 标题 24pt 以上，正文 14pt 以上（离得远也能看清的大小）
- **字体**: 黑体比较易读
- **留白**: 留出充足的空白
- **图的尺寸**: 操作方法的图要画大一些
- **打印**: 推荐彩色打印
:::

### 标签的模板构成

```
┌──────────────────────────────┐
│                              │
│    【作品名】（大字）           │
│                              │
│    作者: ○○ ○○               │
│                              │
│ ─────────────────────────── │
│                              │
│    【概念】                   │
│    （100 字左右的说明文）       │
│                              │
│ ─────────────────────────── │
│                              │
│    【操作方法】               │
│    （图示 + 简洁的说明）       │
│                              │
│                              │
└──────────────────────────────┘
```

## 问卷的制作

### 用 Google 表单制作的步骤

用 Google 表单制作体验会上使用的问卷。

#### 1. 打开 Google 表单

1. 登录 Google 账号
2. 访问 [Google 表单](https://forms.google.com/)
3. 点击 **「空白」** 创建新的表单
4. 把表单的标题设为「作品名 + 体验问卷」

#### 2. 追加 SD 法的问卷项目

SD 法（Semantic Differential method，语义差异法）是使用形容词对来评价印象的方法。

**设置步骤:**

1. 追加问题，把类型改为 **「单选网格（均等刻度）」**
2. 在最小值的标签中输入左侧的形容词（例: 「暗」）
3. 在最大值的标签中输入右侧的形容词（例: 「亮」）
4. 把刻度设为 **1〜7**（7 级评价）
5. 对所有形容词对重复以上操作

::: tip SD 法的详情
形容词对的选择方法与分析方法的详情，请参照 [SD法（印象评价）](/zh/evaluation/sd-method)。
:::

#### 3. 追加 UEQ-S 的问卷项目

UEQ-S（User Experience Questionnaire - Short version）是从「实用性品质」与「感性品质」两个视角评价用户体验的方法。

**设置步骤:**

1. 与 SD 法同样，用 **「均等刻度」** 追加问题
2. 追加 UEQ-S 的 8 个项目
3. 把刻度设为 **1〜7**

::: tip UEQ-S 的详情
项目的内容与分析表的使用方法，请参照 [UEQ-S（UX评价）](/zh/evaluation/ueq-s)。
:::

#### 4. 追加自由填写栏

最后，追加自由填写的问题。

**要追加的问题示例:**

| 问题 | 类型 |
|------|------|
| 「请告诉我们作品好的地方」 | 段落（长文回答） |
| 「如果有觉得需要改进的地方，请告诉我们」 | 段落（长文回答） |
| 「其他感想请自由填写」 | 段落（长文回答） |

#### 5. 表单的设置

1. 在设置标签页中设为 **「不收集邮箱地址」**（匿名问卷）
2. 用预览确认运行情况
3. 生成 **二维码** 并贴在标签上会很方便

::: warning 制作问卷时的注意事项
- 把必填项目减到最少（降低回答的门槛）
- 问题的文字要简短明确
- 为了能在体验后立刻回答，请做成手机上也容易作答的版式
:::
