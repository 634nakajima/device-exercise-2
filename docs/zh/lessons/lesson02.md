了解设备艺术・声音艺术的世界，用 micro:bit 的各种传感器制作乐器。最后初次接触 Pure Data（Pd）。

## 设备艺术・声音艺术介绍

### 设备艺术的特征

设备艺术是把技术当作「表现本身」而非「工具」的艺术。

- **交互性**: 对观众的操作・动作作出反应
- **身体性**: 使用身体的操作成为艺术的一部分
- **实时性**: 对输入实时地改变声音或影像

### 著名作品案例

- **特雷门琴**（1920年）: 只需靠近手即可演奏的世界首个电子乐器
- **TENORI-ON**（岩井俊雄，2007年）: 触摸 LED 网格来创作音乐的设备
- **Reactable**（2003年〜）: 在桌面上放置方块来创造声音的界面
- **Sound of Honda / Ayrton Senna 1989**: 将 F1 行驶数据转换为声音的声音装置

### 声音艺术的手法

- **环境音的活用**: 将日常的声音升华为艺术
- **身体的延伸**: 用设备将身体的动作转换为声音
- **数据的声音化（Sonification）**: 用声音来表现数据

::: tip 想一想
如果要把「身边的动作」转换成声音，你会选择什么样的动作？会映射成什么样的声音？
:::

## Step 1: 用触摸传感器敲鼓

使用 micro:bit V2 的触摸传感器（logo 标志）和引脚（P0, P1, P2）制作鼓垫。

### 触摸引脚的使用方法

micro:bit 下部的金色端子（引脚）可以作为触摸传感器使用。

- **P0**: 大端子（从左数第1个）
- **P1**: 大端子（从左数第2个）
- **P2**: 大端子（从左数第3个）
- **GND**: 接地端子（最右端）

::: warning 注意
要使用触摸传感器，需要一只手接触 **GND** 端子，同时用另一只手（或手指）接触 P0〜P2。把鳄鱼夹连接到 GND 再接到铝箔上会很方便。
:::

### 制作方法

1. 在 MakeCode 中新建项目
2. 按如下方式编写程序:

**触摸 P0 时 → 低音鼓的声音**

```
引脚 P0 被触摸时:
  播放音乐「低音鼓」
  在 LED 上显示 "X"
```

**触摸 P1 时 → 军鼓的声音**

```
引脚 P1 被触摸时:
  播放音乐「军鼓」
  在 LED 上显示 "+"
```

**触摸 P2 时 → 踩镲的声音**

```
引脚 P2 被触摸时:
  播放音乐「踩镲」
  在 LED 上显示 "."
```

3. 给各个端子分配不同的鼓声
4. 用「音乐」→「播放声音」选择预设的鼓声

### 在声音分配上下功夫

- 也给 V2 的 **logo 触摸** 分配镲片的声音
- 再给按钮 A、按钮 B 分配其他声音，最多可以发出 6 种声音

## Step 2: 用电子罗盘制作特雷门琴

使用 micro:bit 的电子罗盘（地磁传感器），制作一个音高随朝向而变化的乐器。

### 罗盘传感器说明

- 水平持握 micro:bit 并旋转，即可获取 **方位角**
- 数值范围: **0〜359**（度）
- 北 = 0°、东 = 90°、南 = 180°、西 = 270°

::: warning 校准
初次使用罗盘时，micro:bit 的屏幕上会显示「TILT TO FILL SCREEN」。倾斜 micro:bit 使所有 LED 点亮，即可完成校准。
:::

### 从方位到频率的映射

将方位角（0〜359）转换为声音的频率。

```
一直重复:
  方位 = 罗盘的方向
  频率 = 映射数值(方位, 0, 359, 200, 2000)
  用该频率发出声音
```

1. 使用「输入」→「更多」→ **「罗盘方向」** 积木
2. 用「计算」→ **「映射数值」** 将 0〜359 转换为 200〜2000（Hz）
3. 把转换后的数值传给「音乐」→ **「播放音调」**

### 应用创意

- 根据方位发出不同的音阶（Do Re Mi Fa Sol La Si Do）
- 只有朝向特定方位时才发出声音
- 用按钮切换八度

## Step 3: 接触 Pure Data

### 什么是 Pure Data（Pd）

**Pure Data（Pd）** 是通过可视化编程进行声音合成与多媒体处理的开源软件。

- **开发者**: Miller Puckette（1990年代〜）
- **特征**: 用连接线（patch cord）连接对象（方框）来编写程序
- **用途**: 电子音乐、声音装置、交互艺术
- **免费**: 开源，任何人都可以使用

### Pd 的种类

| 名称 | 说明 |
|------|------|
| **Pd vanilla** | Miller Puckette 开发的官方版（最小限度的功能） |
| **Pd-extended** | 附带大量库的扩展版（已停止开发） |
| **Plugdata** | 具有现代 UI 的 Pd 兼容环境（也可作为 VST 插件运行） |

本课程使用 **plugdata**。

### 关于 plugdata

**[plugdata](https://plugdata.org/)** 是以 Pure Data 为基础的现代可视化编程环境。它与 Pd vanilla 兼容，同时具备更易用的界面。

| 特征 | 说明 |
|------|------|
| **现代 UI** | 支持深色模式、易于阅读的界面。支持对象的自动补全与拖放 |
| **Pd 兼容** | 可以直接打开 Pd vanilla 的补丁。本网站介绍的 Pd 操作与对象在 plugdata 中同样可用 |
| **内置库** | ELSE、cyclone 等课程中使用的库已预先内置，无需额外安装 |
| **VST/AU 插件** | 也可作为 DAW（GarageBand、Ableton Live 等）的插件运行 |
| **跨平台** | 支持 Mac / Windows / Linux |

::: tip 大学的电脑已安装
plugdata 已经安装在大学的电脑上。如果想安装到自己的电脑上，请从 [plugdata 官方网站](https://plugdata.org/) 下载。
:::

::: warning 与 Pd vanilla 的区别
操作方法和对象名称与 Pd vanilla 相同，但快捷键和外观略有不同。本网站的截图取自 Pd vanilla，不过在 plugdata 中用同样的操作也能得到同样的结果。
:::

## Pure Data 的基本 UI

启动 plugdata（或 Pd vanilla），确认基本的画面构成吧。

- **补丁窗口**: 创建程序（补丁）的工作区
- **对象（object）**: 用 `Ctrl+1`（Mac: `Cmd+1`）可以放置新的对象
- **消息（message）**: 用 `Ctrl+2`（Mac: `Cmd+2`）可以放置消息框
- **编辑/运行模式的切换**: `Ctrl+E`（Mac: `Cmd+E`）

新建一个补丁，试着放置对象和消息吧。下一讲将正式开始使用。
