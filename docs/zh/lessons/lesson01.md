# 第1讲 导论

一起来接触 micro:bit，制作使用传感器的简单乐器吧。

## 本讲目标

- 理解 micro:bit 的基本用法
- 使用光线传感器制作类似「特雷门琴」的乐器
- 使用加速度传感器制作「手铃」
- 了解设备艺术与声音艺术的概要

## 需要准备的物品

| 物品 | 说明 |
|---------|------|
| micro:bit V2 | 内置传感器的单片机开发板 |
| USB 线 | 连接 micro:bit 与电脑（micro USB） |
| 电脑 | Windows 或 Mac |
| 头戴式耳机 / 入耳式耳机 | 用于确认声音 |

## 什么是 micro:bit

micro:bit 是 BBC（英国广播公司）面向教育开发的小型单片机开发板。它内置了以下传感器与设备。

- **LED 显示屏**（5×5）
- **按钮**（A / B 两个）
- **加速度传感器**（检测倾斜与振动）
- **光线传感器**（将 LED 用作光传感器）
- **地磁传感器（电子罗盘）**
- **触摸传感器**（V2 的 logo 标志）
- **麦克风・扬声器**（V2）
- **无线通信**（Bluetooth / Radio）

编程使用 **MakeCode 编辑器**。可以在浏览器上进行积木式编程。

::: tip MakeCode 编辑器
访问 [https://makecode.microbit.org/](https://makecode.microbit.org/)，点击「新建项目」即可开始开发。
:::

## Step 1: micro:bit 的基本操作

### MakeCode 编辑器的使用方法

1. 用浏览器访问 [makecode.microbit.org](https://makecode.microbit.org/)
2. 点击 **「新建项目」**
3. 输入项目名称（例：「特雷门琴」）

### 编辑器画面的构成

- **左侧**: micro:bit 模拟器（可以在电脑上确认程序的运行情况）
- **中央**: 积木类别（选择想要使用的积木）
- **右侧**: 编程区域（组合积木）

### 程序的传输方法

1. 用 USB 线连接 micro:bit 与电脑
2. 点击编辑器左下方的 **「下载」** 按钮
3. （如果没有自动传输）将下载的 `.hex` 文件复制到 micro:bit 驱动器

::: tip 配对
在 MakeCode 编辑器「下载」按钮旁边的「...」中选择「Connect device」，即可进行 USB 配对。配对之后，只需按下下载按钮就能直接传输。
:::

## Step 2: 用光线传感器制作特雷门琴

**特雷门琴（Theremin）** 是通过手的靠近与远离来改变音高的电子乐器。让我们使用 micro:bit 的光线传感器，制作一个类似的乐器。

### 光线传感器的原理

micro:bit 的 LED 显示屏也可以作为检测光量的传感器使用。

- **明亮的地方**: 数值大（最大 255）
- **昏暗的地方**: 数值小（最小 0）
- 用手遮住 LED 数值就会变化

### 制作方法

1. 在 MakeCode 编辑器中新建项目
2. 组装以下积木:

**程序的流程:**

```
一直重复:
  亮度 → 转换为频率
  用该频率发出声音
```

3. 使用「输入」类别中的 **「亮度」** 积木
4. 使用「音乐」类别中的 **「播放音调」** 积木
5. 将亮度的数值（0〜255）映射到频率（200〜2000 Hz 左右）
6. 使用「计算」类别的 **「映射数值」** 积木进行转换

### 通过串口通信将数值发送到电脑

要在电脑上确认传感器的数值，可以使用串口通信。

1. 从「串口通信」类别中添加 **「串口写入数值」** 积木
2. 将标签设为「light」，数值设为「亮度」积木
3. 用 MakeCode 的「显示控制台」按钮即可实时确认数值

::: warning 注意
使用串口通信时，数据会经由 USB 发送到电脑。在之后与 Pure Data 联动的课程中，这个串口通信非常重要。
:::

## Step 3: 用加速度传感器制作手铃

让我们制作一个摇动 micro:bit 就会发声的 **手铃**。

### 加速度传感器的原理

加速度传感器可以检测 micro:bit 的运动（倾斜・振动・冲击）。

- **X 轴**: 左右的倾斜
- **Y 轴**: 前后的倾斜
- **Z 轴**: 上下的运动
- **strength（强度）**: 各方向的合成值

### 制作方法

1. 在 MakeCode 编辑器中新建项目
2. 按以下流程编写程序:

**程序的流程:**

```
被摇动（shake）时:
  发出声音（例: Do 音，500ms）
  在 LED 上显示音符图标
```

3. 使用「输入」类别中的 **「摇动时」** 积木
4. 用「音乐」类别的 **「播放音调」** 设定喜欢的音阶
5. 用「基本」类别的 **「显示图标」** 显示音符图标

### 应用: 分配多个声音

也可以通过改变摇动方式来发出多个声音。

- **「摇动时」** → Do
- **「logo 朝上时」** → Re
- **「logo 朝下时」** → Mi
- **「屏幕朝上时」** → Fa

::: details 挑战
试着使用加速度的强度（strength），根据摇动的力度来改变音量。使用「输入」→「更多」→「加速度 strength」。
:::

## 什么是设备艺术・声音艺术

### 设备艺术

**设备艺术（Device Art）** 是指使用电子设备和传感器创作的艺术作品。它具有 **交互性** 的特征——观众触摸设备或活动身体时，作品会随之变化。

### 声音艺术

**声音艺术（Sound Art）** 是以「声音」为主要素材的艺术表现。与传统音乐不同，它将环境音、噪声、电子音等一切声音都作为表现的对象。

在本课程中，我们将结合 **micro:bit 的传感器** 与 **Pure Data 的声音合成**，制作属于自己的交互式声音艺术作品。
