# 第11讲 多声道音频播放

学习使用多个扬声器进行声音空间演出的方法。为展示做准备，掌握多声道音频的基础。

## 本讲目标

- 学习多声道的声音输出方法，实现空间性的声音演出
- 了解声景（Soundscape）・空间音乐・氛围音乐的概念
- 在 Pd 中设置 4 声道音频播放
- 理解展示空间的扬声器布置

## 声景・空间音乐・氛围音乐

### 声景

**声景（Soundscape）** 是意为「声音的风景」的词。这是加拿大作曲家 **R. Murray Schafer** 提出的概念，是把环绕我们的环境音作为艺术来把握的思路。

- 街道的喧嚣、鸟鸣、河水的潺潺声等，一切环境音都是对象
- 有一种提高对「聆听」的意识的实践方法叫做 **声音漫步（Sound Walk）**
- 是把声音环境本身作为设计对象的构想

### 空间音乐

**空间音乐** 是活用扬声器的布置，在空间上表现声音的音乐。

- 通过从多个扬声器发出不同的声音，可以营造声音在空间中移动的体验
- 特征是用声音包裹听者、具有 **沉浸感** 的体验
- 常用于电子音乐与声音装置

### 氛围音乐

**氛围音乐（Ambient Music）** 是重视环境与氛围的音乐流派。

- 一般认为是英国音乐家 **Brian Eno** 确立了这一概念
- 具有「既可以聆听，也可以忽视的音乐」的特征
- 大量使用缓慢的变化、反复、持续音
- 对声音艺术作品的声音设计有很大影响

::: details 参考：活用空间音响的作品案例
- **声音装置**: 在美术馆或画廊展示的作品，观众在空间中行走时会听到不同的声音
- **多声道音乐会**: 在被 4 台以上扬声器环绕的空间中进行的演奏・演出
- **交互空间**: 与传感器联动，声音随人的动作在空间中移动
:::

## 音频输出的基础

### 单声道・立体声・多声道的区别

| 方式 | 声道数 | 特征 |
|-----|-----------|------|
| **单声道** | 1ch | 从 1 个扬声器输出。没有声音的定位 |
| **立体声** | 2ch | 从左右扬声器输出。可以做左右的定位 |
| **4ch（四声道）** | 4ch | 从前后左右的扬声器输出。可以做空间性的定位 |
| **环绕声** | 5.1ch 以上 | 像电影院那样的立体音响 |

### 在 Pd 中设置多声道输出

#### 1. 打开音频设置

1. 选择 Pd 菜单的 **「媒体」→「音频设置」**
2. 在 **输出设备** 中选择支持多声道的音频接口
3. 把 **输出声道数** 设为 `4` 以上
4. 按「OK」应用设置

::: warning 音频接口的确认
电脑内置的扬声器输出通常最多只有 2 声道（立体声）。要输出 4 声道以上，需要支持多声道的音频接口。请确认课程中使用的器材。
:::

#### 2. dac~ 的多声道指定

给 `[dac~]` 对象加上参数，就可以指定输出目标的声道。

```
[dac~ 1 2]      ← 输出到声道 1 与 2（通常的立体声）
[dac~ 3 4]      ← 输出到声道 3 与 4
[dac~ 1 2 3 4]  ← 输出到声道 1〜4 的全部
```

**声道编号的对应:**

| 声道 | 一般的扬声器位置 |
|-----------|-------------------|
| 1 | 前方左（Front Left） |
| 2 | 前方右（Front Right） |
| 3 | 后方左（Rear Left） |
| 4 | 后方右（Rear Right） |

## 在 Pd 中进行 4ch 音频播放

### 基本构成：用 4 个扬声器播放不同的音源

使用 `[else/play.file~]`，把 4 个音频文件分别从不同的扬声器播放出来。

![4ch音频播放](/images/pd/39-4ch-playback.png)

**补丁的构成:**

1. 用 4 个 `[else/play.file~]` 分别读取不同的音频文件
   - `4chsample_L.wav` — 左前
   - `4chsample_R.wav` — 右前
   - `4chsample_Ls.wav` — 左后
   - `4chsample_Rs.wav` — 右后
2. 在各个 `[else/play.file~]` 的参数中指定 `1 1`，启用循环播放・自动播放
3. 用 `[*~]` 调整各音源输出的音量
4. 把 4 个输出连接到 `[else/out4~]`

::: tip 音频文件的准备
4ch 用的音频文件请放在与补丁相同的文件夹中。把环境音（风、水、鸟鸣等）分别从不同的扬声器播放出来，就能营造出空间性的声音扩展感。
:::

### 4ch 声像定位 — `else/pan4~`

使用 `[else/pan4~]`，可以指定 2D 空间上的位置，把声音分配给 4 个扬声器。

![4ch声像定位](/images/pd/40-4ch-panning.png)

**补丁的构成:**

1. 把 `[noise~]` 等音源输入到 `[else/pan4~]`
2. 用 `[else/slider2d]` 操作 X/Y 坐标（-1〜1）
3. 用 `[unpack f f]` 分离 X 与 Y 的数值，送到 `[else/pan4~]` 的第 2・第 3 入口
4. 把 `[else/pan4~]` 的 4 个出口连接到 `[else/out4~]`

用鼠标拖动 `[else/slider2d]`，音源的位置就会实时变化。如果输入 micro:bit 加速度传感器的 X/Y 数值，就可以用倾斜来控制声音的位置。

### 音源的旋转

也可以让声音在 4 个扬声器之间自动旋转移动。

![音源的旋转](/images/pd/41-rotation.png)

**补丁的构成:**

1. 准备 `[noise~]` 等音源
2. 把音源输入到 `[else/rotate~ 4]` — 这个对象会让声音在 4 个声道之间自动旋转
3. 旋转速度用 `[else/float2sig~ 100]` 等控制（数值越大旋转越快）
4. 用滑块（-0.5〜0.5）操作旋转的速度与方向 — 正值为顺时针，负值为逆时针
5. 把 4 个出口连接到 `[else/out4~]`

::: tip 旋转速度的调整
`[else/float2sig~]` 的参数（例: 100）是转换为信号时的平滑度。旋转速度由滑块的数值决定。为 0 时停止，数值增大则高速旋转。请配合作品的节奏进行调整。
:::

## 展示空间的准备

### 扬声器布置的基本

4 声道的情况下，以体验者为中心，把扬声器布置成正方形（或长方形）。

```
     【前方】
  SP1 ─────── SP2
   |           |
   |   体验者   |
   |     ●     |
   |           |
  SP3 ─────── SP4
     【后方】
```

**布置的要点:**

1. **扬声器的朝向**: 让所有扬声器都朝向体验者的方向（中央）
2. **距离**: 尽可能布置成均等的距离（1.5m〜3m 左右）
3. **高度**: 对准体验者耳朵的高度（坐在椅子上时，以坐姿的耳朵高度为准）
4. **与墙的距离**: 扬声器紧贴墙壁会强调低音，因此要离开 30cm 以上

### 线缆的走线

::: warning 安全上的注意事项
- 用 **养生胶带把线缆固定在地面上**，防止绊倒事故
- **不要把** 电源线与音频线 **捆在一起**（会成为噪声的原因）
- 让线缆的长度留有余量，即使被拉扯也不会脱落

:::

### 音量平衡的调整方法

1. 依次给各个声道播放 **相同的测试音**（例: `[osc~ 1000]`）
2. 站在体验位置（中央），确认来自各个扬声器的音量 **听起来是否均等**
3. 音量偏大的扬声器，在 Pd 一侧用 `[*~]` 调低
4. 让全部声道同时发声，确认听起来是否自然

## 在作品中的应用

把多声道输出运用到自己的作品中吧。

| 创意 | 实现方法 |
|---------|---------|
| 声音在体验者周围旋转 | 用 `[phasor~]` 做 4ch 旋转 |
| 用传感器移动声音的位置 | 加速度 X → 左右声像，加速度 Y → 前后声像 |
| 每个扬声器发出不同的声音 | 把 4 个音源分别输出到不同的声道 |
| 用环境音包裹空间 | 用噪声或环境音以 4ch 包围 |
