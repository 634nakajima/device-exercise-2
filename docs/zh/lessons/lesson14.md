# 第14讲 问卷分析

分析在体验会上收集的问卷数据，客观地评价作品。

## 本讲目标

- 分析收集到的问卷数据，客观地进行作品评价
- 把 SD 法的结果绘制成图表，将印象可视化
- 使用 UEQ-S 的分析表，计算 UX 分数
- 从自由填写中提取改进的线索

## 需要准备的物品

| 物品 | 说明 |
|---------|------|
| 电脑 | Excel 或 Google 表格 |
| 问卷的回答数据 | 从 Google 表单下载 |
| UEQ-S 分析表 | 从官方网站下载 |

---

## SD 法的分析步骤

### 1. 从 Google 表单下载回答

1. 打开 Google 表单
2. 点击 **「回复」** 标签页
3. 点击右上角的 **表格图标**
4. 选择「创建新电子表格」
5. Google 表格会打开，确认其内容

::: tip 以 CSV 下载的情况
「回复」标签页 → 右上角的「︙」菜单 → 选择「下载回复（.csv）」，就可以作为 CSV 文件下载。也可以用 Excel 打开进行分析。
:::

### 2. 计算各形容词对的平均值

对每个形容词对（例: 「暗 - 亮」），计算全体回答者的平均值。

**步骤（Google 表格的情况）:**

1. 确认各个问题所在的列（例: B 列是「暗 - 亮」的回答）
2. 在数据最后一行下方的单元格中，输入以下公式

```
=AVERAGE(B2:B20)
```

（B2〜B20 请根据回答数据的范围进行修改）

3. 对所有形容词对同样地计算平均值

**计算结果的示例:**

| 形容词对 | 平均值 |
|---------|-------|
| 暗 (1) ← → (7) 亮 | 5.2 |
| 安静 (1) ← → (7) 喧闹 | 3.8 |
| 冰冷 (1) ← → (7) 温暖 | 4.6 |
| 无聊 (1) ← → (7) 有趣 | 5.8 |

### 3. 折线图的制作

把平均值作为折线图（SD 剖面图）可视化。

**在 Excel / Google 表格中的步骤:**

1. **数据的准备**
   - 在 A 列输入形容词对左侧的形容词
   - 在 B 列输入平均值
   - （需要比较时）在 C 列输入另一件作品的平均值

2. **插入图表**
   - 选择数据范围
   - 点击「插入」→「图表」
   - 在图表类型中选择 **「折线图」**

3. **图表的格式设置**
   - 在横轴上显示形容词对
   - 把纵轴的范围固定为 **1〜7**
   - 在中间值（4.0）处画一条 **基准线**
   - 把图表标题设为「SD 法剖面图」

::: details 图表制作的详细步骤（Google 表格）
1. 在 A1〜A8 输入形容词（左侧）
2. 在 B1〜B8 输入平均值
3. 选择 A1:B8
4. 菜单「插入」→「图表」
5. 在图表编辑器中把「图表类型」改为「折线图」
6. 点击「自定义」标签页
7. 「纵轴」→ 把「最小值」设为 `1`，「最大值」设为 `7`
8. 「网格线和刻度线」→ 把刻度线的间隔设为 `1`
9. 根据需要追加图表标题・轴标签
:::

### 4. 图表的解读与考察

从完成的 SD 剖面图中，解读以下要点。

| 确认要点 | 应当观察的内容 |
|------------|------------|
| **整体的倾向** | 哪些项目接近 7（偏向积极一侧） |
| **与中间值的比较** | 哪些项目高于/低于 4.0（中间） |
| **与意图的一致性** | 是否与自己想表现的印象一致 |
| **离散程度** | 标准差大的项目说明回答者之间印象存在分歧 |

## UEQ-S 的分析步骤

### 1. 把回答数据复制到分析表

使用 UEQ-S 的官方分析表（Excel）进行分析。

**步骤:**

1. 下载 UEQ-S 的分析表（课上分发，或从官方网站获取）
2. 打开 Google 表单的回答数据
3. 把 UEQ-S 的 8 个项目的回答，复制粘贴到分析表的相应位置
4. 分析表会自动计算分数

::: warning 复制数据时的注意事项
- 把 Google 表单的回答值（1〜7）原样复制
- 确认项目的顺序是否与分析表一致
- 确认有没有空白或异常值
:::

### 2. 解读分析表的图表

分析表中会自动生成以下图表。

| 图表 | 解读的内容 |
|-------|------------|
| **各项目平均分** | 8 个项目各自的平均值 |
| **各量表分数** | 实用性品质（PQ）与感性品质（HQ）的平均值 |
| **总体分数** | UEQ-S 的综合分数 |

**UEQ-S 分数的解读:**

| 分数范围 | 评价 |
|----------|------|
| 低于 -0.8 | 消极评价 |
| -0.8 〜 0.8 | 中立评价 |
| 0.8 〜 2.0 | 积极评价 |
| 2.0 以上 | 非常积极的评价 |

### 3. 与基准（Benchmark）的比较

UEQ-S 的分析表具有与其他产品或服务进行比较（基准对比）的功能。

- **Excellent（前 10%）**: 非常优秀的 UX
- **Good（前 25%）**: 优秀的 UX
- **Above Average（前 50%）**: 高于平均的 UX
- **Below Average（后 50%）**: 低于平均的 UX
- **Bad（后 25%）**: 需要改进的 UX

::: tip UEQ-S 的详情
分数的计算方法与基准的详细看法，请参照 [UEQ-S（UX评价）](/zh/evaluation/ueq-s)。
:::

## 自由填写的分析

### 共通评论的提取

阅读自由填写的回答，找出共通的关键词与主题。

**步骤:**

1. 阅读所有自由填写的回答
2. 把相似的评论归为一组
3. 给各组贴上标签（例: 「操作方法」「声音的质量」「概念」）
4. 找出被提及较多的主题

### 积极/消极的分类

把评论分为积极与消极两类，把握各自的倾向。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
自由填写分析表
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 积极的评论
┌─────────────────────────────────────┐
│ ・「一倾斜声音就变，很直观很有趣」          │
│ ・「深海的氛围传达得很好」                 │
│ ・「气泡的声音很真实，很开心」              │
│                                         │
│ → 共通主题: 操作的直观性、世界观的表现      │
└─────────────────────────────────────┘

■ 消极的评论
┌─────────────────────────────────────┐
│ ・「一开始不知道该做什么」                 │
│ ・「声音太小听不清楚」                     │
│ ・「不知道按钮的功能」                     │
│                                         │
│ → 共通主题: 初始操作的引导、音量、说明不足   │
└─────────────────────────────────────┘
```

## 考察的要点

以分析结果为基础，从以下视角进行考察。

### 1. 是否传达了预期的印象

- 看着 SD 法的剖面图，把自己所追求的印象与实际的评价作比较
- 例: 「明明想营造温暖的氛围，却被评价为偏向『冰冷』一侧」→ 思考为什么会这样

### 2. UX 的实用性品质 / 感性品质的平衡

- **实用性品质（PQ）** 高 → 操作易懂、好用
- **感性品质（HQ）** 高 → 有趣、快乐、有刺激性
- **两者都高** → 既好用又有趣的理想作品
- **PQ 低・HQ 高** → 有趣但操作不易懂 → 改进操作方法会有效
- **PQ 高・HQ 低** → 好用但缺乏趣味 → 在演出上下功夫会有效

### 3. 应当改进之处

以考察为基础，把「如果今后还要进一步改良作品的话要做什么」具体地整理出来。

| 分析结果 | 改进的方向 |
|---------|------------|
| 操作方法不易懂 | 改进标签、提升操作的直观性 |
| 声音的变化小 | 扩大传感器数值的映射 |
| 概念传达不到 | 追加背景音、重新审视声音的选择 |
| 体验单调 | 追加交互的变化 |
