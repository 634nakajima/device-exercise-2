# UEQ-S（User Experience Questionnaire - Short version）

## UEQ-S란?

**UEQ-S** 는 제품이나 서비스의 **사용자 경험（UX）의 품질** 을 손쉽게 측정할 수 있는 설문 방법입니다. 단 **8개의 질문** 으로 경험의 좋고 나쁨을 객관적으로 수치화할 수 있습니다.

::: tip SD법과의 차이
- **SD법** → 작품의 「인상」을 잰다（밝다, 화려하다, 자연스럽다 등）
- **UEQ-S** → 작품의 「경험의 품질」을 잰다（사용하기 편하다, 재미있다, 새롭다 등）

SD법이 「어떤 느낌?」을 묻는 것에 비해, UEQ-S는 「써 보니 어땠어?」를 묻는 것입니다.
:::

## UX（사용자 경험）란

UX는 사용자가 제품이나 서비스를 사용하는 경험 전체의 품질입니다. 스마트폰 앱을 예로 생각해 봅시다:

**사용의 편의성（실용적 품질）**
- 메뉴를 알기 쉽다
- 조작에서 헤매지 않는다
- 하고 싶은 것을 바로 할 수 있다

**즐거움・매력（감성적 품질）**
- 디자인이 세련되다
- 쓰면서 즐겁다
- 다른 데서는 없는 경험을 할 수 있다

좋은 UX란 이 두 가지의 균형이 잡힌 상태입니다.

## 8개의 질문 항목

UEQ-S에서는 다음 8개의 형용사쌍에 대해 7단계로 응답합니다.

### 실용적 품질（Pragmatic Quality）을 재는 4개 항목

| # | 왼쪽 | 오른쪽 | 무엇을 재고 있는가 |
|---|------|------|------|
| 1 | 방해가 된다 (obstructive) | 도움이 된다 (supportive) | 작품이 체험자의 행동을 도와주는가 |
| 2 | 복잡하다 (complicated) | 간단하다 (easy) | 조작이나 이해의 어려움 |
| 3 | 효율이 나쁘다 (inefficient) | 효율이 좋다 (efficient) | 목적을 달성하기까지의 수고 |
| 4 | 어수선하다 (confusing) | 깔끔하다 (clear) | 조작 방법이나 반응을 알기 쉬움 |

### 감성적 품질（Hedonic Quality）을 재는 4개 항목

| # | 왼쪽 | 오른쪽 | 무엇을 재고 있는가 |
|---|------|------|------|
| 5 | 지루하다 (boring) | 흥미진진하다 (exciting) | 경험의 재미・흥분 |
| 6 | 흥미롭지 않다 (not interesting) | 흥미롭다 (interesting) | 호기심을 자극하는가 |
| 7 | 종래와 같다 (conventional) | 독창적이다 (inventive) | 새로움・독자성 |
| 8 | 평범하다 (usual) | 참신하다 (leading edge) | 선진적・혁신적인 인상 |

::: details 응답의 이미지
```
방해가 된다  ◯───◯───◯───◯───◯───◯───◯  도움이 된다
              1   2   3   4   5   6   7
```
각 항목에 대해 왼쪽 형용사에 가까울수록 1, 오른쪽에 가까울수록 7을 고릅니다.
:::

## Google 설문지로 설문을 만드는 절차

### Step 1: 양식의 작성

1. [Google Forms](https://forms.google.com) 를 연다
2. 「빈 양식」을 선택
3. 제목：「〇〇（작품명）의 UX 평가 설문」
4. 설명문을 추가:

```
이 작품을 체험한 감상에 대해 다음 각 항목에 응답해 주세요.
각 형용사쌍에 대해 당신의 경험에 가장 가까운 위치를 골라 주세요.
직관적으로 응답해 주세요（너무 깊이 생각하지 마세요）.
```

### Step 2: 질문의 작성

8개의 형용사쌍 각각에 대해:

1. 「질문 추가」（＋버튼）를 클릭
2. 질문 형식을 「**균등 눈금**」으로 변경
3. 1〜7의 눈금을 설정
4. 라벨을 설정:
   - 1의 라벨: 왼쪽 형용사
   - 7의 라벨: 오른쪽 형용사
5. 「필수」를 켠다

::: warning 순서에 주의
UEQ-S의 질문은 위의 순서대로 나열해 주세요. 연구로 검증된 포맷이므로, 순서를 바꾸면 결과의 타당성에 영향을 줄 가능성이 있습니다.
:::

## 데이터의 분석 절차

### Step 1: 데이터의 다운로드

1. Google 설문지의 「응답」 탭을 연다
2. 스프레드시트 아이콘을 클릭
3. 「파일」→「다운로드」→「Microsoft Excel (.xlsx)」

### Step 2: 점수의 변환

응답 데이터（1〜7）를 UEQ-S의 분석용 점수（-3〜+3）로 변환합니다.

**변환 방법：** 응답값 - 4 = 점수

| 응답값 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|--------|---|---|---|---|---|---|---|
| 점수 | -3 | -2 | -1 | 0 | +1 | +2 | +3 |

::: warning 부정이 왼쪽인 항목에 주의
항목 1〜4（실용적 품질）는 왼쪽이 부정적인 형용사이므로, 응답값을 그대로 변환합니다. 항목 5〜8（감성적 품질）도 마찬가지입니다.

다만 UEQ-S의 **공식 분석 시트** 를 사용하는 경우에는 자동으로 변환되므로 이 절차는 필요 없습니다.
:::

### Step 3: 분석 시트의 사용（권장）

UEQ-S에는 공식 분석용 Excel 시트가 준비되어 있습니다.

1. 분석 시트를 연다（수업에서 배포, 또는 [UEQ 공식 사이트](https://www.ueq-online.org/) 에서 다운로드）
2. 시트를 **복제** 한 뒤에 사용한다
3. 「Data」 시트에 응답 데이터（1〜7의 값）를 복사해 붙여넣는다
4. 「Results」 시트에 자동으로 그래프가 생성된다

### Step 4: 결과의 해석

분석 시트에서 생성되는 그래프에는 주로 다음이 포함됩니다:

#### 평균값의 그래프

```
              -3   -2   -1    0   +1   +2   +3
              |    |    |    |    |    |    |
실용적 품질 PQ  ─────────────────────■■■■■─────
감성적 품질 HQ  ──────────────────────────■■■■■
전체     Overall ───────────────────────■■■■──
```

- **+1.0 이상**: 긍정적인 평가
- **-1.0〜+1.0**: 중립（어느 쪽이라고도 할 수 없다）
- **-1.0 이하**: 부정적인 평가

#### 벤치마크 비교

분석 시트에는 다른 제품의 UEQ-S 결과의 벤치마크 데이터가 포함되어 있습니다. 자기 작품의 결과를 다른 제품과 비교할 수 있습니다.

| 벤치마크 카테고리 | 의미 |
|------|------|
| Excellent（최고） | 상위 10%에 든다 |
| Good（좋음） | 상위 25%에 든다 |
| Above Average（평균 이상） | 상위 50%에 든다 |
| Below Average（평균 이하） | 하위 50% |
| Bad（나쁨） | 하위 25% |

## 결과의 고찰 요점

### 실용적 품질（PQ）이 높은 경우
→ 조작 방법을 알기 쉽고 직관적으로 사용할 수 있었다

### 실용적 품질（PQ）이 낮은 경우
→ 조작 방법을 알기 어렵다, 반응이 기대와 다르다
→ **개선안**: 캡션에 조작 방법을 그림으로 제시한다, 센서의 반응을 조정한다

### 감성적 품질（HQ）이 높은 경우
→ 새롭고 재미있는 경험을 할 수 있었다, 설렜다

### 감성적 품질（HQ）이 낮은 경우
→ 흔하다고 느꼈다, 특별히 인상에 남지 않았다
→ **개선안**: 인터랙션에 의외성을 더한다, 음향의 표현을 궁리한다

### PQ와 HQ의 균형

| 패턴 | 해석 | 개선 방향 |
|------|------|------|
| PQ 높음・HQ 높음 | 이상적인 경험 | 유지・한층 더 다듬기 |
| PQ 높음・HQ 낮음 | 사용하기 편하지만 지루하다 | 연출이나 의외성의 추가 |
| PQ 낮음・HQ 높음 | 재미있지만 사용하기 불편하다 | 조작성의 개선, 가이드의 추가 |
| PQ 낮음・HQ 낮음 | 전반적으로 개선이 필요 | 콘셉트의 재검토 |

## 슬라이드로 정리하기

분석 결과를 1〜2장의 슬라이드로 정리해 봅시다:

**슬라이드1: UEQ-S의 결과 그래프**
- 실용적 품질・감성적 품질의 점수 그래프
- 벤치마크 비교（가능하다면）
- 응답자 수

**슬라이드2: 고찰**
- PQ/HQ의 균형에 대해
- 특히 높은/낮은 항목
- 개선안
