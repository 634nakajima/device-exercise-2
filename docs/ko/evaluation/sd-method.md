# SD법（Semantic Differential법）

## SD법이란?

**SD법** 은 사람이 어떤 것에 대해 느끼는 「인상」을 수치화하는 방법입니다. 1957년에 오스굿（Osgood）이 제안했습니다.

예를 들어 어떤 음악을 들었을 때, 여러분은 「밝은 느낌」「여유로운 느낌」「자연스러운 느낌」과 같은 인상을 받을지도 모릅니다. SD법은 이러한 **말로 표현하기 어려운 감각을 수치로 변환해서 객관적으로 분석할 수 있게 하는** 것입니다.

## 친근한 예로 이해해 보자

마음에 드는 카페를 친구에게 소개할 때, 이런 식으로 설명하지 않나요?

> 「그 카페, 정말 차분한 분위기고, 세련됐지만 캐주얼하고, 너무 밝지도 어둡지도 않고…」

SD법은 이것을 체계적으로 수행합니다. 「차분하다↔시끄럽다」「세련되다↔촌스럽다」「밝다↔어둡다」와 같은 **형용사 쌍** 을 준비해서, 각각 몇 단계로 응답하게 합니다.

## 구조

### 형용사쌍

SD법에서는 의미가 반대인 형용사를 쌍으로 묶어 사용합니다. 이것을 「형용사쌍」이라고 부릅니다.

```
밝다 ──────────── 어둡다
화려하다 ──────────── 수수하다
편안하다 ──────────── 불안하다
```

### 단계 평가

각 형용사쌍에 대해 7단계（또는 5단계）로 응답합니다.

```
밝다  ◯───◯───◯───◯───◯───◯───◯  어둡다
       3   2   1   0  -1  -2  -3

（어느 쪽도 아니면 한가운데의 0）
```

- 왼쪽 형용사에 가깝다고 느끼면 왼쪽으로 치우쳐 응답
- 오른쪽 형용사에 가깝다고 느끼면 오른쪽으로 치우쳐 응답
- 어느 쪽도 아니라면 한가운데

## 이 수업에서 사용하는 형용사쌍

다음 20개 항목을 기본 세트로 사용합니다. 필요에 따라 추가・변경해 주세요.

|---|------|------|
| 1 | 밝다 | 어둡다 |
| 2 | 조화롭다 | 어수선하다 |
| 3 | 여유롭다 | 답답하다 |
| 4 | 독특하다 | 흔하다 |
| 5 | 화려하다 | 수수하다 |
| 6 | 떠들썩하다 | 쓸쓸하다 |
| 7 | 깨끗하다 | 지저분하다 |
| 8 | 동적이다 | 정적이다 |
| 9 | 복잡하다 | 단순하다 |
| 10 | 환상적이다 | 현실적이다 |
| 11 | 편안하다 | 불안하다 |
| 12 | 능동적이다 | 수동적이다 |
| 13 | 자연스럽다 | 인공적이다 |
| 14 | 선명하다 | 칙칙하다 |
| 15 | 약동감이 있다 | 차분하다 |
| 16 | 매력적이다 | 지루하다 |
| 17 | 새롭다 | 낡았다 |
| 18 | 인상적이다 | 인상이 옅다 |
| 19 | 감정적이다 | 냉정하다 |
| 20 | 박력이 있다 | 밋밋하다 |

::: tip 형용사쌍을 고르는 법
위의 것은 어디까지나 기본입니다. 자기 작품의 콘셉트와 관련된 형용사쌍을 추가하면 더 유의미한 분석을 할 수 있습니다. 예를 들어 「바다」를 모티프로 한 작품이라면 「시원하다↔따뜻하다」「개방적이다↔폐쇄적이다」 등을 추가해 봅시다.
:::

## Google 설문지로 설문을 만드는 절차

### Step 1: 양식의 작성

1. [Google Forms](https://forms.google.com) 를 연다
2. 「빈 양식」을 선택
3. 양식의 제목을 입력（예：「〇〇（작품명）의 인상 평가 설문」）
4. 설명문을 추가:

```
이 작품을 체험한 인상에 대해 다음 각 항목에 응답해 주세요.
각 형용사쌍에 대해 당신의 인상에 가장 가까운 위치를 골라 주세요.
```

### Step 2: 질문 항목의 작성

각 형용사쌍에 대해:

1. 「질문 추가」（＋버튼）를 클릭
2. 질문 형식을 「**균등 눈금**」으로 변경
3. 1〜7의 눈금을 설정
4. 라벨을 설정:
   - 1의 라벨: 왼쪽 형용사（예：「밝다」）
   - 7의 라벨: 오른쪽 형용사（예：「어둡다」）
5. 「필수」를 켠다

::: warning 주의
형용사의 좌우 배치（긍정이 왼쪽/오른쪽）는 무작위로 섞는 것이 바람직합니다. 전부 같은 방향으로 맞추면 응답자가 생각 없이 응답하는 「반응 편향」이 생길 수 있습니다.
:::

### Step 3: 응답의 수집

1. 양식 오른쪽 위의 「보내기」 버튼을 클릭
2. 링크 아이콘으로 URL을 얻는다
3. 체험자에게 URL을 공유하고, 작품 체험 후에 응답하게 한다

## 데이터의 분석 절차

### Step 1: 데이터의 다운로드

1. Google 설문지의 「응답」 탭을 연다
2. 스프레드시트 아이콘（초록색）을 클릭
3. 새 스프레드시트가 열린다
4. 「파일」→「다운로드」→「Microsoft Excel (.xlsx)」

### Step 2: 평균값의 계산

Excel에서 각 형용사쌍의 평균값을 계산합니다.

1. 응답 데이터 아래 행에 「평균」이라고 입력
2. 각 열（형용사쌍）에 대해 `=AVERAGE(B2:B11)` 과 같은 수식을 입력
   - B2〜B11은 응답 데이터의 범위（응답자 수에 맞춰 조정）

### Step 3: 꺾은선 그래프의 작성

1. 형용사쌍의 이름과 평균값을 선택
2. 「삽입」→「차트」→「꺾은선 그래프」
3. 다음과 같은 그래프를 작성:
   - 가로축: 형용사쌍（왼쪽 형용사를 표시）
   - 세로축: 평균값（1〜7）
   - 중앙선（4.0）을 추가하면 보기 좋다

::: details 그래프의 이미지
```
     1    2    3    4    5    6    7
밝다 ─────────●─────────────────── 어둡다
조화롭다 ────────────●──────────────── 어수선하다
여유롭다 ──────●───────────────────── 답답하다
독특하다 ────●─────────────────────── 흔하다
     ...
```
각 항목의 평균값을 점으로 표시하고, 그것을 선으로 이은 것이 SD법의 프로파일 그래프입니다.
:::

### Step 4: 고찰

그래프를 보면서 다음 사항을 고찰해 주세요:

- **의도한 대로 인상이 전달되었는가?**
  - 「환상적인 분위기」를 목표로 했다 → 「환상적이다↔현실적이다」의 점수를 확인
- **특히 강한/약한 인상은?**
  - 평균값이 극단적으로 높은/낮은 항목에 주목
- **예상 밖의 결과는 있었는가?**
  - 의도하지 않았던 인상이 강하게 나타난 경우, 그 원인을 생각한다

::: tip 체험의 시점별로 평가하는 경우
작품 체험 중에 큰 인상 변화가 예상되는 경우에는, 체험의 각 시점（「처음 작품을 봤을 때」「장치를 만졌을 때」「체험을 마쳤을 때」 등）에 응답하게 하면 체험의 변화를 분석할 수 있습니다. 같은 양식 안에 섹션을 나누어 만들면 좋습니다.
:::

## 슬라이드로 정리하기

분석 결과를 1〜2장의 슬라이드로 정리해 봅시다:

**슬라이드1: 그래프와 개요**
- SD법의 프로파일 그래프
- 응답자 수, 작품명

**슬라이드2: 고찰**
- 특징적인 인상（높은/낮은 점수）
- 의도와의 일치/불일치
- 개선안
