# 제15강 최종 보고회

작품의 제작 과정과 평가 결과를 프레젠테이션으로 발표합니다.

## 이번 강의의 목표

- 작품과 조사 결과를 프레젠테이션으로 발표한다
- 콘셉트・기술 구성・평가 결과・고찰을 논리적으로 전달한다
- 다른 수강생의 발표를 듣고 질의응답에 참여한다

## 준비물

| 항목 | 설명 |
|---------|------|
| 프레젠테이션 슬라이드 | Google 슬라이드 / PowerPoint |
| 작품의 데모 영상 | 조작하는 모습을 녹화한 것 |
| 분석 결과의 그래프 | SD법 프로파일, UEQ-S의 그래프 |

---

## 프레젠테이션의 구성

다음 다섯 개의 섹션으로 발표를 구성해 봅시다.

### 1. 작품의 소개

**전달할 것:**
- **작품명**
- **콘셉트** --- 무엇을 표현하고 싶었는가
- **모티프** --- 테마나 소재는 무엇인가
- **인터랙션** --- 어떤 조작으로 소리가 변화하는가

**슬라이드 예시:**

```
┌──────────────────────────────────┐
│                                  │
│     작품명: 「해중 산책」          │
│                                  │
│  콘셉트:                          │
│  심해의 세계를 소리로 체험하는 작품.│
│  micro:bit의 기울기로 수심이 변하고,│
│  빛의 양으로 거품 소리가 바뀐다.   │
│                                  │
│     [작품의 사진 or 일러스트]      │
│                                  │
└──────────────────────────────────┘
```

::: tip 데모 영상을 활용하자
실제로 조작하는 모습을 영상으로 보여 주면 발표가 훨씬 이해하기 쉬워집니다. 30초〜1분 정도의 짧은 영상을 준비합시다. 스마트폰으로 촬영하는 것만으로도 충분합니다.
:::

### 2. 기술 구성

**전달할 것:**
- 사용한 센서의 종류와 역할
- Pd 패치의 구성（주요 오브젝트）
- 데이터의 흐름（입력 → 처리 → 출력）

**슬라이드 예시:**

```
┌──────────────────────────────────┐
│                                  │
│     기술 구성                     │
│                                  │
│  [입력]         [처리]    [출력]  │
│  가속도Y축 ──→ osc~  ──→ dac~   │
│  밝기     ──→ noise~ ──→        │
│  버튼A    ──→ 모드 전환          │
│                                  │
│  주요 Pd 오브젝트:                │
│  osc~, noise~, lop~, bp~,       │
│  delwrite~, delread~, line~     │
│                                  │
└──────────────────────────────────┘
```

::: tip Pd 패치의 스크린샷
Pd 패치의 스크린샷을 슬라이드에 붙이면 기술적인 구성이 전달되기 쉬워집니다. 패치가 복잡한 경우에는 주요 부분을 확대해서 보여 줍시다.
:::

### 3. 평가 결과

**전달할 것:**
- SD법의 프로파일（꺾은선 그래프）
- UEQ-S의 점수（실용적 품질 / 감성적 품질）
- 자유 기술의 주요 코멘트

**SD법의 그래프:**
- 지난 강의에서 만든 꺾은선 그래프를 크게 표시한다
- 특히 주목해야 할 항목을 화살표나 하이라이트로 강조한다

**UEQ-S의 그래프:**
- 실용적 품질（PQ）과 감성적 품질（HQ）의 점수를 막대그래프로 표시한다
- 벤치마크와의 비교 결과를 제시한다

**자유 기술:**
- 대표적인 코멘트를 2〜3건 인용한다
- 긍정적인 것과 부정적인 것을 모두 다룬다

### 4. 고찰

**전달할 것:**
- 의도한 인상과 실제 평가의 비교
- UX의 실용적 품질과 감성적 품질의 균형
- 성공한 점과 개선해야 할 점
- 사고 발화법에서 얻은 피드백과의 관련

**고찰의 구성 예시:**

```
【의도와 결과의 비교】
- 목표로 했던 인상: ○○
- SD법의 결과: △△ → 대체로 의도대로 / 예상과 달랐다

【UX의 평가】
- 실용적 품질: □□ → 조작의 이해하기 쉬움에 대해
- 감성적 품질: ◇◇ → 재미나 자극에 대해

【개선점】
- 만약 더 개량한다면...
```

### 5. 정리와 감상

**전달할 것:**
- 제작을 통해 배운 것
- 기술적인 면에서 성장한 점
- 앞으로 살리고 싶은 것
- 전체적인 감상

## 슬라이드 작성의 요점

### 슬라이드 1장에 메시지 1개

슬라이드 1장에서 전달할 것은 **하나만** 으로 합시다.

| 나쁜 예 | 좋은 예 |
|-------|-------|
| 콘셉트와 기술 구성과 평가 결과를 1장에 몰아넣는다 | 콘셉트로 1장, 기술 구성으로 1장, 평가 결과로 1장 |

### 그래프는 크게, 라벨은 읽기 쉽게

- 그래프는 슬라이드의 **절반 이상** 크기로 표시한다
- 축 라벨이나 데이터 라벨은 **뒷자리에서도 읽을 수 있는 크기** 로 한다
- 색은 3색 이내로 억제한다
- 중요한 데이터 포인트에는 화살표나 주석을 붙인다

::: warning 그래프 작성 시의 주의
- 세로축의 범위를 적절히 설정한다（SD법은 1〜7, UEQ-S는 -3〜3）
- 가로축의 라벨이 겹치지 않도록 한다（필요하면 줄바꿈이나 약칭을 사용）
- 그래프 제목을 반드시 붙인다
:::

### 데모 영상의 준비

1. 스마트폰으로 작품을 조작하는 모습을 **가로 방향** 으로 촬영한다
2. 영상의 길이는 **30초〜1분** 으로 한다
3. 다음 내용을 촬영한다:
   - 기본적인 조작（센서를 움직이는 방법）
   - 소리의 변화를 알 수 있는 장면
   - 재미있는 조작이나 특징적인 장면
4. 슬라이드에 영상을 삽입하거나, 발표 중에 재생한다

::: tip 영상이 재생되지 않을 때를 대비해서
프로젝터나 PC의 환경에 따라 영상이 재생되지 않을 수 있습니다. 영상의 캡처 이미지（스크린샷）도 슬라이드에 넣어 두면 안심입니다.
:::

## 슬라이드의 구성 예시

| 슬라이드 번호 | 내용 | 예상 시간 |
|------------|------|---------|
| 1 | 제목（작품명, 이름） | - |
| 2 | 콘셉트・모티프 | 1분 |
| 3 | 데모 영상 / 조작하는 모습 | 1분 |
| 4 | 기술 구성（센서 → Pd → 출력） | 1분 |
| 5 | SD법의 평가 결과（그래프） | 1분 |
| 6 | UEQ-S의 평가 결과（그래프） | 1분 |
| 7 | 고찰（의도와 결과의 비교） | 1분 |
| 8 | 정리와 감상 | 1분 |

## 발표 시간의 기준

| 항목 | 시간 |
|------|------|
| **발표** | 5〜7분 |
| **질의응답** | 2〜3분 |
| **합계** | 약 10분 |

::: warning 시간 관리
발표 시간은 반드시 지킵시다. 사전에 리허설을 하고 시간을 재 두는 것을 권장합니다. 특히 데모 영상의 재생 시간도 포함해서 연습합시다.
:::

## 질의응답의 요점

### 질문을 받을 때

- 질문의 내용을 이해하지 못했다면 **되물어서 확인** 한다
- 「모르겠습니다」라고 솔직하게 답해도 괜찮다
- 기술적인 질문에는 구체적으로 답한다
- 개선 제안을 받으면 「감사합니다」라고 받아들인다

### 질문을 할 때

다른 사람의 발표에 대해 다음과 같은 질문을 해 봅시다.

| 질문의 종류 | 예 |
|----------|-----|
| 콘셉트에 대해 | 「이 모티프를 고른 계기는 무엇인가요?」 |
| 기술에 대해 | 「이 소리는 어떤 Pd 오브젝트로 만들었나요?」 |
| 평가에 대해 | 「UEQ-S의 결과에서 의외였던 점이 있나요?」 |
| 제작 과정에 대해 | 「제작 중에 가장 힘들었던 점은 무엇인가요?」 |
| 발전에 대해 | 「앞으로 더 발전시킨다면 무엇을 추가하겠습니까?」 |

::: tip 좋은 질문을 하기 위해
발표를 들으면서 신경 쓰였던 것이나 재미있다고 생각한 것을 메모해 둡시다. 질문은 발표자에게도 배움의 기회입니다. 적극적으로 질의응답에 참여합시다.
:::
