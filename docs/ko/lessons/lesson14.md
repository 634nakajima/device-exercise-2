# 제14강 설문 분석

체험회에서 수집한 설문 데이터를 분석해서, 작품을 객관적으로 평가합니다.

## 이번 강의의 목표

- 수집한 설문 데이터를 분석해서 작품의 평가를 객관적으로 수행한다
- SD법의 결과를 그래프로 만들어 인상을 시각화한다
- UEQ-S의 분석 시트를 사용해 UX 점수를 산출한다
- 자유 기술에서 개선의 힌트를 추출한다

## 준비물

| 항목 | 설명 |
|---------|------|
| PC | Excel 또는 Google 스프레드시트 |
| 설문의 응답 데이터 | Google 설문지에서 다운로드 |
| UEQ-S 분석 시트 | 공식 사이트에서 다운로드 |

---

## SD법의 분석 절차

### 1. Google 설문지에서 응답 다운로드

1. Google 설문지를 연다
2. **「응답」** 탭을 클릭한다
3. 오른쪽 위의 **스프레드시트 아이콘** 을 클릭한다
4. 「새 스프레드시트 만들기」를 선택한다
5. Google 스프레드시트가 열리므로 내용을 확인한다

::: tip CSV로 다운로드하는 경우
「응답」 탭 → 오른쪽 위의 「︙」 메뉴 → 「응답 다운로드（.csv）」를 선택하면 CSV 파일로 다운로드할 수 있습니다. Excel에서 열어 분석할 수도 있습니다.
:::

### 2. 각 형용사쌍의 평균값을 계산하기

각 형용사쌍（예: 「어둡다 - 밝다」）에 대해 전체 응답자의 평균값을 계산합니다.

**절차（Google 스프레드시트의 경우）:**

1. 각 질문의 열을 확인한다（예: B열이 「어둡다 - 밝다」의 응답）
2. 데이터의 마지막 행 아래 셀에 다음 수식을 입력한다

```
=AVERAGE(B2:B20)
```

（B2〜B20은 응답 데이터의 범위에 맞춰 변경한다）

3. 모든 형용사쌍에 대해 같은 방법으로 평균값을 계산한다

**계산 결과의 예:**

| 형용사쌍 | 평균값 |
|---------|-------|
| 어둡다 (1) ← → (7) 밝다 | 5.2 |
| 조용하다 (1) ← → (7) 시끄럽다 | 3.8 |
| 차갑다 (1) ← → (7) 따뜻하다 | 4.6 |
| 지루하다 (1) ← → (7) 재미있다 | 5.8 |

### 3. 꺾은선 그래프의 작성

평균값을 꺾은선 그래프（SD 프로파일）로 시각화합니다.

**Excel / Google 스프레드시트에서의 절차:**

1. **데이터의 준비**
   - A열에 형용사쌍의 왼쪽 형용사를 입력한다
   - B열에 평균값을 입력한다
   - （비교하는 경우）C열에 다른 작품의 평균값을 입력한다

2. **그래프의 삽입**
   - 데이터 범위를 선택한다
   - 「삽입」→「차트」를 클릭한다
   - 차트 종류에서 **「꺾은선 그래프」** 를 선택한다

3. **그래프의 서식 설정**
   - 가로축에 형용사쌍을 표시한다
   - 세로축의 범위를 **1〜7** 로 고정한다
   - 중앙값（4.0）에 **기준선** 을 긋는다
   - 차트 제목을 「SD법 프로파일」로 한다

::: details 그래프 작성의 상세 절차（Google 스프레드시트）
1. A1〜A8에 형용사（왼쪽）를 입력한다
2. B1〜B8에 평균값을 입력한다
3. A1:B8을 선택한다
4. 메뉴 「삽입」→「차트」
5. 차트 편집기에서 「차트 종류」를 「꺾은선 그래프」로 변경
6. 「맞춤설정」 탭을 클릭
7. 「세로축」→「최솟값」을 `1`, 「최댓값」을 `7` 로 설정
8. 「격자선 및 눈금」→ 눈금의 간격을 `1` 로 설정
9. 필요에 따라 차트 제목・축 라벨을 추가
:::

### 4. 그래프의 해석과 고찰

완성된 SD 프로파일에서 다음 요점을 읽어 냅시다.

| 확인 요점 | 봐야 할 것 |
|------------|------------|
| **전체의 경향** | 7에 가까운（긍정적인 쪽으로 치우친） 항목은 무엇인가 |
| **중앙값과의 비교** | 4.0（중간）보다 높은/낮은 항목은 어느 것인가 |
| **의도와의 일치** | 자신이 표현하고자 했던 인상과 일치하는가 |
| **편차** | 표준편차가 큰 항목은 응답자 간에 인상이 갈리고 있다 |

## UEQ-S의 분석 절차

### 1. 응답 데이터를 분석 시트에 복사

UEQ-S의 공식 분석 시트（Excel）를 사용해 분석합니다.

**절차:**

1. UEQ-S의 분석 시트를 다운로드한다（수업에서 배포, 또는 공식 사이트에서 입수）
2. Google 설문지의 응답 데이터를 연다
3. UEQ-S의 8개 항목의 응답을 분석 시트의 해당 위치에 복사&붙여넣기 한다
4. 분석 시트가 자동으로 점수를 계산한다

::: warning 데이터를 복사할 때의 주의
- Google 설문지의 응답값（1〜7）을 그대로 복사한다
- 항목의 순서가 분석 시트와 일치하는지 확인한다
- 빈칸이나 이상값이 없는지 확인한다
:::

### 2. 분석 시트의 그래프 해석하기

분석 시트에는 다음 그래프가 자동으로 생성됩니다.

| 그래프 | 해석할 내용 |
|-------|------------|
| **항목별 평균 점수** | 8개 항목 각각의 평균값 |
| **척도별 점수** | 실용적 품질（PQ）과 감성적 품질（HQ）의 평균값 |
| **전체 점수** | UEQ-S의 종합 점수 |

**UEQ-S 점수의 해석:**

| 점수 범위 | 평가 |
|----------|------|
| -0.8 미만 | 부정적 평가 |
| -0.8 〜 0.8 | 중립적 평가 |
| 0.8 〜 2.0 | 긍정적 평가 |
| 2.0 이상 | 매우 긍정적인 평가 |

### 3. 벤치마크와의 비교

UEQ-S의 분석 시트에는 다른 제품이나 서비스와의 비교（벤치마크） 기능이 있습니다.

- **Excellent（상위 10%）**: 매우 뛰어난 UX
- **Good（상위 25%）**: 뛰어난 UX
- **Above Average（상위 50%）**: 평균 이상의 UX
- **Below Average（하위 50%）**: 평균 이하의 UX
- **Bad（하위 25%）**: 개선이 필요한 UX

::: tip UEQ-S의 상세
점수의 계산 방법이나 벤치마크를 보는 자세한 방법은 [UEQ-S（UX 평가）](/ko/evaluation/ueq-s) 을 참조해 주세요.
:::

## 자유 기술의 분석

### 공통된 코멘트의 추출

자유 기술의 응답을 읽고, 공통된 키워드나 테마를 찾습니다.

**절차:**

1. 모든 자유 기술 응답을 읽는다
2. 비슷한 코멘트를 그룹으로 묶는다
3. 각 그룹에 라벨을 붙인다（예: 「조작 방법」「소리의 질」「콘셉트」）
4. 많이 언급된 테마를 특정한다

### 긍정/부정의 분류

코멘트를 긍정과 부정으로 분류하고, 각각의 경향을 파악합니다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
자유 기술 분석 시트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 긍정적인 코멘트
┌─────────────────────────────────────┐
│ ・「기울이면 소리가 바뀌는 게 직관적이고 재밌다」│
│ ・「심해의 분위기가 잘 전달되었다」          │
│ ・「거품 소리가 리얼해서 즐거웠다」          │
│                                         │
│ → 공통 테마: 조작의 직관성, 세계관의 표현   │
└─────────────────────────────────────┘

■ 부정적인 코멘트
┌─────────────────────────────────────┐
│ ・「처음에 뭘 해야 할지 몰랐다」            │
│ ・「소리가 작아서 알아듣기 어려웠다」        │
│ ・「버튼의 기능을 몰랐다」                 │
│                                         │
│ → 공통 테마: 초기 조작의 안내, 음량, 설명 부족│
└─────────────────────────────────────┘
```

## 고찰의 요점

분석 결과를 바탕으로 다음 관점에서 고찰을 진행합니다.

### 1. 의도한 대로 인상이 전달되었는가

- SD법의 프로파일을 보고, 자신이 목표로 한 인상과 실제 평가를 비교한다
- 예: 「따뜻한 분위기를 목표로 했는데 『차갑다』 쪽으로 평가되었다」→ 왜 그렇게 되었는지 생각한다

### 2. UX의 실용적 품질 / 감성적 품질의 균형

- **실용적 품질（PQ）** 이 높다 → 조작이 알기 쉽고 사용하기 편하다
- **감성적 품질（HQ）** 이 높다 → 재미있고 즐겁고 자극적이다
- **양쪽 다 높다** → 사용하기 편하고 재미있는 이상적인 작품
- **PQ 낮음・HQ 높음** → 재미있지만 조작을 알기 어렵다 → 조작 방법의 개선이 효과적
- **PQ 높음・HQ 낮음** → 사용하기 편하지만 재미가 부족하다 → 연출의 궁리가 효과적

### 3. 개선해야 할 점

고찰을 바탕으로, 앞으로 작품을 더 개량한다면 무엇을 할지 구체적으로 정리해 봅시다.

| 분석 결과 | 개선의 방향성 |
|---------|------------|
| 조작 방법을 알기 어렵다 | 캡션의 개선, 조작의 직관성 향상 |
| 소리의 변화가 작다 | 센서 값의 매핑을 확대 |
| 콘셉트가 전달되지 않는다 | 배경음의 추가, 소리 선택의 재검토 |
| 체험이 단조롭다 | 인터랙션의 배리에이션 추가 |

::: tip 최종 보고회를 향해
이번 분석 결과는 제15강의 최종 보고회에서 프레젠테이션에 사용합니다. 그래프의 스크린샷을 저장해 둡시다. 고찰의 내용도 메모해 두면 슬라이드 작성이 수월해집니다.
:::
