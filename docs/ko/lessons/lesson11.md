# 제11강 멀티채널 오디오 재생

여러 대의 스피커를 사용한 소리의 공간적인 연출 방법을 배웁니다. 전시를 위해 멀티채널 오디오의 기초를 익힙시다.

## 이번 강의의 목표

- 멀티채널로 음향을 출력하는 방법을 배우고, 공간적인 소리의 연출을 실현한다
- 사운드스케이프・공간 음악・앰비언트 음악의 개념을 안다
- Pd에서 4채널 오디오 재생을 설정한다
- 전시 공간의 스피커 배치를 이해한다

## 준비물

| 항목 | 설명 |
|---------|------|
| PC | Pure Data가 설치되어 있을 것 |
| 멀티채널 오디오 인터페이스 | 4ch 이상 출력 지원 |
| 스피커 × 4대 | 전시용 |
| 스피커 케이블 | 필요한 길이를 확인 |
| 헤드폰 | 개인 작업 시에 사용 |

## 사운드스케이프・공간 음악・앰비언트 음악

### 사운드스케이프

**사운드스케이프（Soundscape）** 는 「소리의 풍경」을 뜻하는 말입니다. 캐나다의 작곡가 **R. Murray Schafer** 가 제창한 개념으로, 우리를 둘러싼 환경음을 예술로서 파악하는 사고방식입니다.

- 거리의 소음, 새의 지저귐, 시냇물 소리 등 모든 환경음이 대상
- 「듣는」 것에 대한 의식을 높이는 **사운드 워크** 라는 실천 방법이 있다
- 소리 환경 자체를 디자인한다는 발상

### 공간 음악

**공간 음악** 은 스피커의 배치를 살려 소리를 공간적으로 표현하는 음악입니다.

- 여러 스피커에서 서로 다른 소리를 냄으로써, 소리가 공간을 이동하는 경험을 만들 수 있다
- 청취자를 소리로 감싸는 **몰입감** 있는 경험이 특징
- 전자 음악이나 사운드 인스톨레이션에서 자주 사용된다

### 앰비언트 음악

**앰비언트 음악（Ambient Music）** 은 환경이나 분위기를 중시하는 음악 장르입니다.

- 영국의 음악가 **Brian Eno** 가 개념을 확립한 것으로 알려져 있다
- 「들을 수도 있고, 무시할 수도 있는 음악」이라는 특징
- 느린 변화, 반복, 지속음이 많이 사용된다
- 사운드 아트 작품의 음향 설계에 큰 영향을 주고 있다

::: details 참고: 공간 음향을 활용한 작품 사례
- **사운드 인스톨레이션**: 미술관이나 갤러리의 전시 작품으로, 관객이 공간을 걸으면 서로 다른 소리가 들린다
- **멀티채널 콘서트**: 4대 이상의 스피커로 둘러싸인 공간에서의 연주・공연
- **인터랙티브 공간**: 센서와 연동해서 사람의 움직임에 따라 소리가 공간 안을 이동한다
:::

## 오디오 출력의 기초

### 모노・스테레오・멀티채널의 차이

| 방식 | 채널 수 | 특징 |
|-----|-----------|------|
| **모노** | 1ch | 하나의 스피커에서 출력. 소리의 정위 없음 |
| **스테레오** | 2ch | 좌우의 스피커에서 출력. 좌우의 정위가 가능 |
| **4ch（쿼드）** | 4ch | 전후좌우의 스피커에서 출력. 공간적인 정위가 가능 |
| **서라운드** | 5.1ch 이상 | 영화관 같은 입체 음향 |

### Pd에서의 다채널 출력 설정

#### 1. 오디오 설정 열기

1. Pd 메뉴의 **「미디어」→「오디오 설정」** 을 선택한다
2. **출력 장치** 에 멀티채널을 지원하는 오디오 인터페이스를 선택한다
3. **출력 채널 수** 를 `4` 이상으로 설정한다
4. 「OK」를 눌러 설정을 적용한다

::: warning 오디오 인터페이스의 확인
PC의 내장 스피커 출력은 보통 2채널（스테레오）까지입니다. 4채널 이상의 출력에는 멀티채널을 지원하는 오디오 인터페이스가 필요합니다. 수업에서 사용하는 기자재를 확인해 주세요.
:::

#### 2. dac~ 의 다채널 지정

`[dac~]` 오브젝트에 인수를 붙임으로써 출력할 채널을 지정할 수 있습니다.

```
[dac~ 1 2]      ← 채널 1과 2로 출력（일반적인 스테레오）
[dac~ 3 4]      ← 채널 3과 4로 출력
[dac~ 1 2 3 4]  ← 채널 1〜4 전부로 출력
```

**채널 번호의 대응:**

| 채널 | 일반적인 스피커 위치 |
|-----------|-------------------|
| 1 | 전방 좌（Front Left） |
| 2 | 전방 우（Front Right） |
| 3 | 후방 좌（Rear Left） |
| 4 | 후방 우（Rear Right） |

## Pd에서의 4ch 오디오 재생

### 기본 구성: 4대의 스피커로 서로 다른 음원을 재생하기

`[else/play.file~]` 를 사용해서, 4개의 음원 파일을 각각 다른 스피커에서 재생합니다.

![4ch 오디오 재생](/images/pd/39-4ch-playback.png)

**패치의 구성:**

1. 4개의 `[else/play.file~]` 로 각각 다른 음원 파일을 읽어 들인다
   - `4chsample_L.wav` — 왼쪽 프런트
   - `4chsample_R.wav` — 오른쪽 프런트
   - `4chsample_Ls.wav` — 왼쪽 리어
   - `4chsample_Rs.wav` — 오른쪽 리어
2. 각 `[else/play.file~]` 의 인수에 `1 1` 을 지정해서 반복 재생・자동 재생을 활성화한다
3. 각 음원의 출력을 `[*~]` 로 음량 조정한다
4. 4개의 출력을 `[else/out4~]` 에 연결한다

::: tip 음원 파일의 준비
4ch용 음원 파일은 패치와 같은 폴더에 두세요. 환경음（바람, 물, 새소리 등）을 각각 다른 스피커에서 흘려보냄으로써 공간적인 소리의 확산을 만들 수 있습니다.
:::

### 4ch 패닝 — `else/pan4~`

`[else/pan4~]` 를 사용하면 2D 공간상의 위치를 지정해서 4대의 스피커에 소리를 배분할 수 있습니다.

![4ch 패닝](/images/pd/40-4ch-panning.png)

**패치의 구성:**

1. `[noise~]` 등의 음원을 `[else/pan4~]` 에 입력한다
2. `[else/slider2d]` 로 X/Y 좌표（-1〜1）를 조작한다
3. `[unpack f f]` 로 X와 Y의 값을 분리해서 `[else/pan4~]` 의 제2・제3 인렛으로 보낸다
4. `[else/pan4~]` 의 4개 아웃렛을 `[else/out4~]` 에 연결한다

`[else/slider2d]` 를 마우스로 드래그하면 음원의 위치가 실시간으로 변화합니다. micro:bit의 가속도 센서의 X/Y 값을 입력하면, 기울기로 소리의 위치를 컨트롤할 수도 있습니다.

### 음원의 회전

4대의 스피커 사이를 소리가 자동으로 회전하듯이 이동시킬 수도 있습니다.

![음원의 회전](/images/pd/41-rotation.png)

**패치의 구성:**

1. `[noise~]` 등의 음원을 준비한다
2. `[else/rotate~ 4]` 에 음원을 입력한다 — 이 오브젝트가 4채널 사이에서 소리를 자동으로 회전시킨다
3. 회전 속도는 `[else/float2sig~ 100]` 등으로 제어한다（값이 클수록 빠르게 회전）
4. 슬라이더（-0.5〜0.5）로 회전 속도와 방향을 조작한다 — 양수면 시계 방향, 음수면 반시계 방향
5. 4개의 아웃렛을 `[else/out4~]` 에 연결한다

::: tip 회전 속도의 조정
`[else/float2sig~]` 의 인수（예: 100）는 시그널로 변환할 때의 매끄러움입니다. 회전 속도는 슬라이더의 값으로 결정됩니다. 0이면 정지, 값을 크게 하면 고속으로 회전합니다. 작품의 템포에 맞춰 조정합시다.
:::

## 전시 공간의 준비

### 스피커 배치의 기본

4채널의 경우, 체험자를 중심으로 정사각형（또는 직사각형）으로 스피커를 배치합니다.

```
     【전방】
  SP1 ─────── SP2
   |           |
   |   체험자   |
   |     ●     |
   |           |
  SP3 ─────── SP4
     【후방】
```

**배치의 요점:**

1. **스피커의 방향**: 모든 스피커를 체험자 쪽（중앙）으로 향하게 한다
2. **거리**: 가능한 한 균등한 거리로 배치한다（1.5m〜3m 정도）
3. **높이**: 체험자의 귀 높이에 맞춘다（의자에 앉는 경우에는 앉은 상태의 귀 높이）
4. **벽으로부터의 거리**: 스피커를 벽에 밀착시키면 저음이 강조되므로 30cm 이상 떨어뜨린다

### 케이블의 배선

::: warning 안전상의 주의
- 케이블은 **양생 테이프로 바닥에 고정** 해서 걸려 넘어지는 사고를 방지한다
- 전원 케이블과 오디오 케이블을 **묶지 않는다**（노이즈의 원인이 된다）
- 케이블의 길이에 여유를 두어 잡아당겨져도 빠지지 않도록 한다
:::

### 음량 밸런스의 조정 방법

1. 각 채널에 **같은 테스트 음** 을 순서대로 흘려보낸다（예: `[osc~ 1000]`）
2. 체험 위치（중앙）에 서서, 각 스피커에서 나는 음량이 **균등하게 들리는지** 확인한다
3. 음량이 큰 스피커는 Pd 쪽의 `[*~]` 로 낮춘다
4. 전 채널에서 동시에 소리를 내어 자연스럽게 들리는지 확인한다

## 작품에의 응용

멀티채널 출력을 자신의 작품에 도입해 봅시다.

| 아이디어 | 실현 방법 |
|---------|---------|
| 소리가 체험자의 주위를 돈다 | `[phasor~]` 로 4ch 로테이션 |
| 센서로 소리의 위치가 움직인다 | 가속도 X → 좌우 팬, 가속도 Y → 전후 팬 |
| 각 스피커에서 서로 다른 소리 | 4개의 음원을 각각 다른 채널로 출력 |
| 환경음으로 공간을 감싼다 | 노이즈나 환경음을 4ch로 포위 |
