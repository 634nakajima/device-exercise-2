# 제12강 완성도를 높이자

체험회를 위해 작품의 음향・캡션・설문을 마무리합니다.

## 이번 강의의 목표

- 작품을 체험회에 맞춰 완성한다
- 음향의 품질을 높인다
- 캡션（작품 해설 패널）을 제작한다
- Google 설문지로 설문을 만든다

## 준비물

| 항목 | 설명 |
|---------|------|
| 자신의 작품 | 개선이 끝난 상태 |
| PC | Pd + Google 계정 |
| micro:bit + USB 케이블 | 작품 구동용 |

---

## 음향의 마무리

### 노이즈 대책

불필요한 노이즈가 발생하지 않았는지 확인합시다.

| 노이즈의 종류 | 원인 | 대책 |
|------------|------|------|
| 「툭」 하는 소리 | 값의 급격한 변화 | `[line~]` 으로 값을 매끄럽게 변화시킨다 |
| 「웅」 하는 낮은 소리 | USB나 전원의 노이즈 | 케이블을 짧게 한다, 루프를 피한다 |
| 「쏴」 하는 소리 | 노이즈 성분이 크다 | `[lop~]` 으로 필터링한다 |
| 소리가 끊긴다 | CPU 부하가 높다 | 블록 크기를 크게 한다（미디어→오디오 설정） |

### 센서의 감도 조정

체험자가 조작하기 쉽도록 센서의 반응을 조정합니다.

**요점:**

1. **데드존의 설정** --- 센서의 유효 범위를 정해서 불필요한 값을 제외한다

센서의 원본 데이터를 `clip` 으로 유효 범위로 제한한 뒤 `cyclone/scale` 로 매핑하면, 상한・하한 양쪽의 데드존을 간단하게 설정할 수 있습니다.

```
[센서 값]
      |
[clip 30 220]           ← 30 미만・220 초과를 잘라 버림
      |
[cyclone/scale 30 220 0 1000]  ← 유효 범위를 출력 범위에 매핑
      |
[출력]
```

> 자세한 내용은 [제4강 클립](/ko/lessons/lesson04#클립-값의-제한) 을 참조해 주세요.

2. **스무딩（평활화）** --- 값의 변화를 매끄럽게 한다

수업에서 소개한 평활화 오브젝트를 사용합시다.

- **`lop~`**: 시그널에 대한 로우패스 필터. 컷오프 주파수를 낮출수록 매끄러워진다
- **`else/smooth~`**: 평활화에 특화된 오브젝트. 인수가 클수록 매끄럽다
- **`else/s2f~`**: 평활화한 시그널을 값으로 되돌린다（`snapshot~` 의 대체）

> 자세한 내용은 [제4강 평활화 처리（스무딩）](/ko/lessons/lesson04#평활화-처리-스무딩) 을 참조해 주세요.

## 캡션의 제작

### 캡션이란

**캡션** 은 전시회장에서 작품 옆에 설치하는 해설 패널입니다. 체험자가 작품을 이해하고 올바르게 조작할 수 있도록 하기 위한 중요한 요소입니다.

### 캡션에 포함할 내용

| 항목 | 내용 | 예 |
|------|-----|-----|
| **작품명** | 작품의 제목 | 해중 산책 |
| **작자명** | 자신의 이름 | 야마다 타로 |
| **콘셉트 설명** | 작품의 의도를 설명 | 심해의 세계를 소리로 표현했다. micro:bit의 기울기로 수심이 바뀌고, 어두움에 따라 거품이 나타난다. |
| **조작 방법** | 그림과 함께 조작 방법을 제시 | 일러스트 포함 |

### 레이아웃의 요점

::: tip A4 크기로 만들 것을 권장
- **글자 크기**: 제목은 24pt 이상, 본문은 14pt 이상（떨어져서도 읽을 수 있는 크기）
- **글꼴**: 고딕체가 읽기 쉽다
- **여백**: 충분한 여백을 둔다
- **그림의 크기**: 조작 방법의 그림은 크게 그린다
- **인쇄**: 컬러 인쇄를 권장
:::

### 캡션의 템플릿 구성

```
┌──────────────────────────────┐
│                              │
│    【작품명】（크게）           │
│                              │
│    작자: ○○ ○○               │
│                              │
│ ─────────────────────────── │
│                              │
│    【콘셉트】                 │
│    （100자 정도의 설명문）      │
│                              │
│ ─────────────────────────── │
│                              │
│    【조작 방법】              │
│    （그림 + 간결한 설명）      │
│                              │
│                              │
└──────────────────────────────┘
```

## 설문의 작성

### Google 설문지로 만드는 절차

체험회에서 사용할 설문을 Google 설문지로 만듭니다.

#### 1. Google 설문지 열기

1. Google 계정에 로그인한다
2. [Google 설문지](https://forms.google.com/) 에 접속한다
3. **「빈 양식」** 을 클릭해서 새 양식을 만든다
4. 양식의 제목을 「작품명 + 체험 설문」으로 한다

#### 2. SD법의 설문 항목 추가하기

SD법（Semantic Differential method）은 형용사쌍을 사용해 인상을 평가하는 방법입니다.

**설정 절차:**

1. 질문을 추가하고 유형을 **「균등 눈금」** 으로 변경한다
2. 최솟값의 라벨에 왼쪽 형용사（예: 「어둡다」）를 입력한다
3. 최댓값의 라벨에 오른쪽 형용사（예: 「밝다」）를 입력한다
4. 눈금을 **1〜7** 로 설정한다（7단계 평가）
5. 모든 형용사쌍에 대해 반복한다

::: tip SD법의 상세
형용사쌍을 고르는 법이나 분석 방법의 상세는 [SD법（인상 평가）](/ko/evaluation/sd-method) 을 참조해 주세요.
:::

#### 3. UEQ-S의 설문 항목 추가하기

UEQ-S（User Experience Questionnaire - Short version）는 사용자 경험을 「실용적 품질」과 「감성적 품질」의 두 가지 관점에서 평가하는 방법입니다.

**설정 절차:**

1. SD법과 마찬가지로 **「균등 눈금」** 으로 질문을 추가한다
2. UEQ-S의 8개 항목을 추가한다
3. 눈금을 **1〜7** 로 설정한다

::: tip UEQ-S의 상세
항목의 내용이나 분석 시트의 사용법은 [UEQ-S（UX 평가）](/ko/evaluation/ueq-s) 을 참조해 주세요.
:::

#### 4. 자유 기술란 추가하기

마지막으로 자유 기술 질문을 추가합니다.

**추가할 질문 예시:**

| 질문 | 유형 |
|------|------|
| 「작품에서 좋았던 점을 알려 주세요」 | 단락（장문 답변） |
| 「개선하는 편이 좋겠다고 생각하는 점이 있으면 알려 주세요」 | 단락（장문 답변） |
| 「그 밖에 감상이 있으면 자유롭게 적어 주세요」 | 단락（장문 답변） |

#### 5. 양식의 설정

1. 설정 탭에서 **「이메일 주소를 수집하지 않음」** 으로 설정한다（익명 설문）
2. 미리 보기로 동작을 확인한다
3. **QR 코드** 를 생성해서 캡션에 붙여 두면 편리하다

::: warning 설문 작성 시의 주의
- 필수 항목은 최소한으로 한다（응답의 문턱을 낮춘다）
- 질문문은 짧고 명확하게 한다
- 체험 직후에 답할 수 있도록, 스마트폰에서도 답하기 쉬운 레이아웃으로 한다
:::

## 체크리스트

- [ ] 음량 밸런스를 확인하고 클리핑이 없는 것을 확인했다
- [ ] 불필요한 노이즈를 제거했다
- [ ] 센서의 감도를 조정했다
- [ ] 캡션（A4 크기）을 만들었다
- [ ] 캡션에 작품명, 작자명, 콘셉트, 조작 방법을 기재했다
- [ ] Google 설문지로 설문을 만들었다
- [ ] SD법의 항목을 추가했다
- [ ] UEQ-S의 항목을 추가했다
- [ ] 자유 기술란을 추가했다
- [ ] 설문의 동작을 확인했다
