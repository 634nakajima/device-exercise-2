# 제13강 작품 체험회와 설문 조사

모두의 작품을 서로 체험하고, 설문으로 데이터를 수집합니다.

## 이번 강의의 목표

- 작품을 다른 수강생에게 체험하게 해서 설문 데이터를 수집한다
- SD법・UEQ-S・자유 기술에 의한 피드백을 얻는다
- 모두의 작품을 체험하고 다양한 표현을 접한다

## 준비물

| 항목 | 설명 |
|---------|------|
| 완성한 작품 | micro:bit + Pd 패치 |
| 캡션 | 지난 강의에서 만든 A4 패널 |
| 설문 URL / QR 코드 | Google 설문지로의 링크 |
| 스마트폰 | 설문 응답용 |
| 스피커 | 소리 출력용 |

---

## 체험회의 흐름

### 전체 타임라인

| 시간 | 내용 |
|------|------|
| 0:00〜0:15 | 세팅 |
| 0:15〜0:20 | 체험회의 설명 |
| 0:20〜1:10 | 작품 체험 + 설문 응답 |
| 1:10〜1:20 | 정리・되돌아보기 |

### 1. 작품의 세팅（15분）

다음 절차로 세팅합시다.

1. **기자재의 연결**
   - micro:bit를 USB 케이블로 PC에 연결한다
   - SerialOSCConverter를 실행하고 연결을 확인한다
   - Pd 패치를 열고 DSP를 ON으로 한다
   - 스피커를 연결하고 소리가 나는지 확인한다

2. **캡션의 설치**
   - 작품 옆에 캡션을 놓는다
   - 체험자가 읽기 쉬운 위치・각도로 한다

3. **설문의 준비**
   - QR 코드를 인쇄해서 캡션 옆에 붙인다
   - 또는 설문 URL을 종이에 적어서 놓아 둔다

::: warning 세팅 시의 확인 사항
- [ ] 소리가 정상적으로 출력되는지
- [ ] 센서가 올바르게 반응하는지
- [ ] 설문의 QR 코드가 인식되는지
- [ ] 케이블이 안전하게 배선되어 있는지
:::

### 2. 캡션의 설치

캡션은 다음 정보가 한눈에 들어오도록 배치합니다.

- **작품명** --- 크고 눈에 띄게
- **조작 방법** --- 그림을 포함해서 알기 쉽게
- **설문 QR 코드** --- 체험 후 바로 응답할 수 있는 위치에

### 3. 작품의 체험（50분）

전원이 순서대로 각 작품을 체험합니다.

**체험의 흐름（작품 하나당）:**

1. 캡션을 읽는다（1분）
2. 작품을 자유롭게 체험한다（3〜5분）
3. 설문에 응답한다（2〜3분）
4. 다음 작품으로 이동한다

::: tip 체험의 요령
- 우선 캡션의 조작 방법을 확인한 뒤에 체험한다
- 여러 가지 조작을 시도해 본다
- 체험 중에 느낀 것을 기억해 두고, 직후에 설문에 응답한다
- 다른 사람이 체험 중일 때는 순서를 기다리거나 다른 작품으로 이동한다
:::

### 4. 설문에의 응답

각 작품을 체험한 후에 스마트폰으로 설문에 응답합니다.

**응답의 절차:**

1. QR 코드를 스마트폰으로 인식한다
2. SD법의 항목에 응답한다（직관적으로 답한다）
3. UEQ-S의 항목에 응답한다（직관적으로 답한다）
4. 자유 기술란에 코멘트를 적는다
5. 제출한다

## SD법에 의한 인상 평가

SD법（Semantic Differential method）에서는 형용사쌍을 사용해서 작품의 인상을 7단계로 평가합니다.

**응답의 요점:**

- **너무 깊이 생각하지 않는다** --- 직관적인 첫인상으로 응답한다
- **중간만 고르지 않도록** --- 되도록 인상에 가까운 쪽을 고른다
- **모든 항목에 응답한다** --- 빈칸이 없도록 한다

::: tip SD법의 상세
형용사쌍의 의미나 분석 방법에 대해서는 [SD법（인상 평가）](/ko/evaluation/sd-method) 을 참조해 주세요.
:::

---

## UEQ-S에 의한 평가

UEQ-S（User Experience Questionnaire - Short version）는 사용자 경험을 **실용적 품질（Pragmatic Quality）** 과 **감성적 품질（Hedonic Quality）** 의 두 가지 관점에서 평가합니다.

**응답의 요점:**

- SD법과 마찬가지로 **직관적** 으로 응답한다
- 8개 항목 전부에 응답한다
- 좌우 어느 쪽 형용사에 가까운지를 7단계로 고른다

::: tip UEQ-S의 상세
각 항목의 의미나 점수의 해석에 대해서는 [UEQ-S（UX 평가）](/ko/evaluation/ueq-s) 을 참조해 주세요.
:::

## 자유 기술 설문

자유 기술에서는 수치로는 표현할 수 없는 구체적인 피드백을 기록합니다.

**적으면 좋은 것:**

- 특히 재미있었던 부분이나 조작
- 개선하면 더 좋아질 것 같은 점
- 소리나 조작에 대해 느낀 것
- 콘셉트에 대한 감상

::: tip 건설적인 피드백
「좋다」「나쁘다」만이 아니라, 「○○ 부분이 △△했기 때문에 □□하면 더 좋아질 것 같다」처럼 **구체적** 으로 적으면 제작자에게 참고가 됩니다.
:::

## 데이터 수집 시의 주의점

### 제작자로서

- 자기 작품 곁에 있으면서 **기자재 문제에 대응** 할 수 있도록 한다
- 다만 체험자에게 **조작 방법을 과도하게 설명하지 않는다**（캡션으로 전달되는지 확인할 좋은 기회）
- 설문에 응답하지 않은 사람이 있으면 자연스럽게 말을 건넨다

### 평가자로서

- **모든 작품** 을 체험하고 설문에 응답한다
- 응답은 **익명** 이므로 솔직한 감상을 적는다
- 체험 **직후** 에 설문에 응답한다（시간이 지나면 인상이 흐려진다）

### 데이터의 품질을 유지하기 위해

- 전원이 모든 작품을 체험할 수 있도록 시간 배분에 주의한다
- 하나의 작품에 너무 오래 머무르지 않는다
- 설문 응답은 **체험 직후** 에 한다

::: warning 중요
설문 데이터는 제14강의 분석에서 사용합니다. 응답이 적으면 분석의 정확도가 떨어지므로, **모든 작품에 응답** 하도록 유의합시다.
:::

## 체크리스트

### 체험회 전

- [ ] 작품이 정상적으로 동작하는 것을 확인했다
- [ ] 캡션을 설치했다
- [ ] 설문의 QR 코드를 설치했다
- [ ] 스피커의 음량을 적절히 조정했다

### 체험회 중

- [ ] 모든 작품을 체험했다
- [ ] 모든 작품의 설문에 응답했다
- [ ] 자유 기술란에 코멘트를 기입했다

### 체험회 후

- [ ] Google 설문지의 응답 수를 확인했다
- [ ] 기자재를 정리했다
